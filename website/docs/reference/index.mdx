# Reference

Quick-lookup tables for the Python surface exposed by gopy. Each table
matches CPython 3.14.

* [Opcodes](opcodes). The full bytecode table with stack effect and oparg shape.
* [Types](types). Built-in types and their slot tables.
* [Builtins](builtins). The `builtins` module.
* [Errors](errors). Exception hierarchy and where each one is raised.
