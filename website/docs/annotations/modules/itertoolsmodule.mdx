# `Modules/itertoolsmodule.c`

<CpyLink path="Modules/itertoolsmodule.c" />

`itertoolsmodule.c` implements the entire `itertools` standard-library module
in C. Every object is a distinct C struct with a `tp_iternext` slot; none of
them hold the full sequence in memory; each produces the next value on demand.

The module contains 18 iterator types. They divide into three groups by
structure. The *infinite iterators* (`count`, `cycle`, `repeat`) run without
a termination condition unless the caller stops pulling. The *filtering and
mapping iterators* (`compress`, `islice`, `dropwhile`, `takewhile`,
`filterfalse`, `starmap`, `accumulate`, `groupby`) each wrap exactly one
source iterator and apply a transformation or predicate per step. The
*combinatoric iterators* (`product`, `permutations`, `combinations`,
`combinations_with_replacement`, `pairwise`, `zip_longest`, `chain`) operate
over a pool of elements captured at construction time or merge several
iterators.

Each iterator type follows the same shape: a `*_new` / `*_init` function that
validates arguments and sets initial state, a `*_next` function registered as
`tp_iternext`, a `*_dealloc` function, and optional `*_reduce` / `*_setstate`
for pickling support.

### `cycle`: two-phase infinite loop (lines 350 to 600)

<CpyLink path="Modules/itertoolsmodule.c" lines="350-600" />

`cycle` has two phases controlled by its `firstpass` flag. During the first
pass it both forwards items and appends them to a `saved` list. Once the
source is exhausted it loops over `saved` indefinitely:

```c
static PyObject *
cycle_next(cycleobject *lz)
{
    if (lz->it != NULL) {
        /* First pass: pull from source. */
        PyObject *item = (*Py_TYPE(lz->it)->tp_iternext)(lz->it);
        if (item != NULL) {
            if (lz->firstpass == 0) {
                if (PyList_Append(lz->saved, item) < 0) {
                    Py_DECREF(item);
                    return NULL;
                }
            }
            return item;
        }
        /* Source exhausted — switch to saved list. */
        Py_CLEAR(lz->it);
        if (PyList_GET_SIZE(lz->saved) == 0)
            return NULL;   /* empty input: stop */
        lz->index = 0;
    }

    /* Subsequent passes: index through saved. */
    PyObject *item = PyList_GET_ITEM(lz->saved, lz->index);
    lz->index++;
    if (lz->index >= PyList_GET_SIZE(lz->saved))
        lz->index = 0;
    Py_INCREF(item);
    return item;
}
```

`firstpass` is set when the object is unpickled via `__setstate__`, indicating
that the `saved` list is already complete and the first-pass accumulation
should be skipped.

### `islice`: lazy slicing with a positional counter (lines 1200 to 1500)

<CpyLink path="Modules/itertoolsmodule.c" lines="1200-1500" />

`islice` tracks a `cnt` integer (the current source position) and a `next`
integer (the source position of the next value to yield). Between `cnt` and
`next` it calls `iternext` and discards:

```c
static PyObject *
islice_next(isliceobject *lz)
{
    PyObject *item;
    Py_ssize_t stop = lz->stop;

    if (lz->cnt >= stop)
        return NULL;

    /* Skip items between last yield and next target. */
    while (lz->cnt < lz->next) {
        item = (*Py_TYPE(lz->it)->tp_iternext)(lz->it);
        if (item == NULL) return NULL;
        Py_DECREF(item);
        lz->cnt++;
    }

    item = (*Py_TYPE(lz->it)->tp_iternext)(lz->it);
    if (item == NULL) return NULL;
    lz->cnt++;
    lz->next += lz->step;
    return item;
}
```

The skip loop never stores the discarded items. `stop = -1` encodes "no stop"
(the `islice(it, start, None)` form). `step` defaults to 1. The constructor
converts the Python `None`-or-int arguments into C `Py_ssize_t` fields,
raising `ValueError` for negative values and `TypeError` for non-integers.

### `groupby` and `_grouper` (lines 2000 to 2300)

<CpyLink path="Modules/itertoolsmodule.c" lines="2000-2300" />

`groupby` yields `(key, group_iterator)` pairs. Consecutive elements with
equal keys form one group. The tricky part is that advancing the outer
`groupby` iterator must exhaust the previous `_grouper` before pulling the
next element from the source:

```c
static PyObject *
groupby_next(groupbyobject *gbo)
{
    PyObject *newvalue, *newkey, *r;

    /* Exhaust the previous grouper before fetching the next key. */
    if (gbo->currgroupe != NULL) {
        for (;;) {
            r = grouper_next((grouperobject *)gbo->currgroupe);
            if (r == NULL) break;
            Py_DECREF(r);
        }
        PyErr_Clear();
        Py_CLEAR(gbo->currgroupe);
    }

    if (gbo->tgtkey == NULL) {
        /* First call: fetch the first element. */
        newvalue = (*Py_TYPE(gbo->it)->tp_iternext)(gbo->it);
        if (newvalue == NULL) return NULL;
        Py_XSETREF(gbo->currvalue, newvalue);
        /* ... compute new key ... */
    }
    /* ... compare tgtkey to currkey, advance until different ... */

    r = PyTuple_Pack(2, gbo->currkey, gbo->currgroupe);
    return r;
}
```

Each `_grouper` holds a back-reference to the parent `groupby` object and
calls `groupby_next_value` (an internal helper) instead of `tp_iternext` on
the source, so that both the outer and inner iterator share the same source
position. This means that holding onto a `_grouper` after the outer iterator
has advanced gives an already-exhausted iterator, not stale data.

### `product`: Cartesian product with mixed-radix indices (lines 2600 to 3000)

<CpyLink path="Modules/itertoolsmodule.c" lines="2600-3000" />

`product` captures copies of all input iterables as tuples at construction
time, then maintains an `indices` array of length `npools` (one entry per
pool, counting from the rightmost):

```c
static PyObject *
product_next(productobject *lz)
{
    PyObject **pools = lz->pools;
    Py_ssize_t *indices = lz->indices;
    Py_ssize_t npools = lz->npools;

    /* Build result tuple from current indices. */
    PyObject *result = PyTuple_New(npools);
    for (Py_ssize_t i = 0; i < npools; i++) {
        PyObject *pool = pools[i];
        PyObject *item = PyTuple_GET_ITEM(pool, indices[i]);
        Py_INCREF(item);
        PyTuple_SET_ITEM(result, i, item);
    }

    /* Advance indices right-to-left (mixed-radix increment). */
    Py_ssize_t i = npools - 1;
    while (i >= 0) {
        indices[i]++;
        if (indices[i] == PyTuple_GET_SIZE(pools[i])) {
            indices[i] = 0;
            i--;
        } else {
            break;
        }
    }
    if (i < 0) {
        lz->stopped = 1;   /* carry propagated past leftmost pool */
    }
    return result;
}
```

The `repeat` keyword argument multiplies each pool `repeat` times by
repeating the pool tuple that many times during construction. The total
iteration count is the product of all pool sizes, which can be very large;
`product` is fully lazy and computes nothing until `next()` is called.
