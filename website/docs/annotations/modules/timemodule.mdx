# `Modules/timemodule.c`

<CpyLink path="Modules/timemodule.c" />

`Modules/timemodule.c` is the sole implementation of CPython's `time`
module. There is no `Lib/time.py`; the module is 100% C. The file
provides six families of functionality:

1. **Clock access** — `time_time` (wall clock as a float), `time_time_ns`
   (wall clock in integer nanoseconds), `time_monotonic` /
   `time_monotonic_ns`, `time_perf_counter` / `time_perf_counter_ns`,
   `time_process_time` / `time_process_time_ns`, and `time_thread_time` /
   `time_thread_time_ns`. Each pair shares a backend that returns a
   `_PyTime_t` (64-bit nanosecond integer) and then converts to a float
   for the non-`_ns` variant.

2. **Sleep** — `time_sleep` which calls `pysleep()`. `pysleep` loops on
   `nanosleep(2)` on POSIX (restarting if interrupted by a non-signal
   `EINTR`) and on `WaitForSingleObjectEx` on Windows.

3. **`struct_time`** — a `structseq` with nine integer fields
   (`tm_year`, `tm_mon`, `tm_mday`, `tm_hour`, `tm_min`, `tm_sec`,
   `tm_wday`, `tm_yday`, `tm_isdst`) plus two optional named extras
   (`tm_gmtoff`, `tm_zone`). It is a subclass of `tuple`.

4. **Calendar conversion** — `time_localtime` and `time_gmtime` convert
   seconds-since-epoch to `struct_time`; `time_mktime` goes the other
   direction.

5. **Formatting** — `time_strftime` wraps `strftime(3)`;
   `time_strptime` is a thin wrapper that delegates to
   `_strptime.strptime_time` (pure Python in `Lib/_strptime.py`).

6. **Timezone** — `time_tzset` calls `tzset(3)` on POSIX to reload the
   `TZ` environment variable; `time_timezone`, `time_altzone`, `time_daylight`,
   and `time_tzname` expose the C `extern` timezone globals.

Clock resolution on each platform:

| Platform | Wall (`CLOCK_REALTIME`) | Monotonic | Perf counter |
| --- | --- | --- | --- |
| Linux | `clock_gettime` | `CLOCK_MONOTONIC` | `CLOCK_MONOTONIC` |
| macOS | `gettimeofday` | `mach_absolute_time` | `mach_absolute_time` |
| Windows | `GetSystemTimeAsFileTime` | `QueryPerformanceCounter` | `QueryPerformanceCounter` |

## Reading

### `time_time` wall-clock read (lines 80 to 250)

<CpyLink path="Modules/timemodule.c" lines="80-250" />

```c
static PyObject *
time_time(PyObject *module, PyObject *unused)
{
    _PyTime_t t;
    if (_PyTime_GetSystemClock(&t) < 0)
        return NULL;
    return _PyTime_AsSecondsDouble_Object(t);
}

static PyObject *
time_time_ns(PyObject *module, PyObject *unused)
{
    _PyTime_t t;
    if (_PyTime_GetSystemClock(&t) < 0)
        return NULL;
    return _PyTime_AsNanosecondsObject(t);
}
```

`_PyTime_t` is a `int64_t` holding nanoseconds since the Unix epoch.
`_PyTime_GetSystemClock` fills it using the best available platform call:
`clock_gettime(CLOCK_REALTIME)` on Linux, `gettimeofday` on older POSIX,
and `GetSystemTimeAsFileTime` on Windows (adjusted from the 100-ns Windows
epoch to the Unix epoch). `_PyTime_AsSecondsDouble_Object` divides by
`1e9` and boxes the result into a Python `float`.

The `_ns` variant skips the float conversion and returns the raw integer
via `_PyTime_AsNanosecondsObject`, which calls `PyLong_FromLongLong`.

### `pysleep` and signal-interrupted sleep (lines 450 to 600)

<CpyLink path="Modules/timemodule.c" lines="450-600" />

```c
static int
pysleep(_PyTime_t timeout)
{
    _PyTime_t deadline = _PyTime_GetMonotonicClock() + timeout;

    do {
        struct timespec timeout_abs;
        _PyTime_AsTimespec(timeout, &timeout_abs);

        Py_BEGIN_ALLOW_THREADS
        int ret = nanosleep(&timeout_abs, NULL);
        Py_END_ALLOW_THREADS

        if (ret == 0)
            break;

        if (errno != EINTR) {
            PyErr_SetFromErrno(PyExc_OSError);
            return -1;
        }

        /* EINTR: check for signals, then re-compute remaining sleep time */
        if (Py_MakePendingCalls() < 0)
            return -1;

        timeout = deadline - _PyTime_GetMonotonicClock();
        if (timeout <= 0)
            break;
    } while (1);
    return 0;
}
```

The loop accounts for early wakeup from `EINTR`: after calling
`Py_MakePendingCalls` (which dispatches any pending signals, including
`KeyboardInterrupt`), it recomputes the remaining duration against the
`deadline` so the full requested sleep time is honoured even across
multiple signal interruptions. On Windows the inner call is replaced by
`WaitForSingleObjectEx(NULL, ms, TRUE)` which already handles the
alertable wait needed for APCs.

```c
    {"tm_year",   "year, for example, 1993"},

    {"tm_mday",   "day of month, range [1, 31]"},
    {"tm_hour",   "hours, range [0, 23]"},
    {"tm_min",    "minutes, range [0, 59]"},
    {"tm_sec",    "seconds, range [0, 61]"},    /* 60-61 for leap seconds */
    {"tm_wday",   "day of week, range [0, 6], Monday is 0"},
    {"tm_yday",   "day of year, range [1, 366]"},
    {"tm_isdst",  "1 if summer time is in effect, 0 if not, and -1 if unknown"},
    {"tm_gmtoff", "offset from UTC in seconds"},  /* optional */
    {"tm_zone",   "abbreviation of timezone name"},  /* optional */
    {0}
};
```

`struct_time` is built with `PyStructSequence_NewType`. The first nine
fields are always present; `tm_gmtoff` and `tm_zone` are set only when
the platform `localtime_r` fills `tm_gmtoff` / `tm_zone` in `struct tm`
(i.e., glibc / BSD / macOS). Accessing them on a Windows `struct_time`
raises `AttributeError`.

### `time_strftime` format-string expansion (lines 1050 to 1350)

<CpyLink path="Modules/timemodule.c" lines="1050-1350" />

```c
static PyObject *
time_strftime(PyObject *module, PyObject *args)
{
    const char *fmt;
    struct tm buf = {0};
    char *outbuf;
    size_t bufsize;

    if (!PyArg_ParseTuple(args, "s|O:strftime", &fmt, &tup))
        return NULL;

    /* fill buf from tup, or use localtime() of current time */
    ...

    /* grow outbuf until strftime fills it completely */
    for (bufsize = 1024; ; bufsize *= 2) {
        outbuf = PyMem_Malloc(bufsize);
        size_t n = strftime(outbuf, bufsize, fmt, &buf);
        if (n > 0 || bufsize > 256*1024) break;
        PyMem_Free(outbuf);
    }
    return PyUnicode_DecodeLocale(outbuf, "surrogateescape");
}
```

`time_strftime` passes control entirely to the platform `strftime(3)`. The
doubling loop is needed because `strftime` returns `0` both when the
output buffer is too small and when the format string legitimately
produces an empty result (e.g., `%Z` on a system with no timezone set).
The loop caps at 256 KB to prevent runaway allocation from a pathological
format string.

`time_strptime` is a one-liner that imports `_strptime` on demand and
calls `_strptime.strptime_time(string, format)`. All parsing logic is
pure Python.

`module/time/module.go` (pending). Clock reads use `time.Now()`,

## CPython 3.14 changes

`_PyTime_t` was renamed to `PyTime_t` and made public in 3.13 as part of
the limited C API extension (PEP 697). `time.time_ns` was added in 3.7.
`time.thread_time` was added in 3.7. `time.perf_counter_ns` was added in
3.7. The `tm_gmtoff` / `tm_zone` extras on `struct_time` have been
available since 3.3.
