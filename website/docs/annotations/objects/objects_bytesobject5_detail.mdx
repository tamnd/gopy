### `bytes.split`

```c
// CPython: Objects/bytesobject.c:1980 bytes_split
static PyObject *
bytes_split_impl(PyBytesObject *self, PyObject *sep, Py_ssize_t maxsplit)
{
    Py_ssize_t len = PyBytes_GET_SIZE(self);
    const char *s = PyBytes_AS_STRING(self);
    if (sep == Py_None) {
        /* Split on whitespace */
        return split_whitespace(s, len, maxsplit);
    }
    /* Split on explicit separator */
    Py_ssize_t n = PyBytes_GET_SIZE(sep);
    const char *sub = PyBytes_AS_STRING(sep);
    return split_char(s, len, sub[0], maxsplit);  /* fast path for 1-byte sep */
}
```

`b'a  b  c'.split()` strips leading/trailing whitespace and splits on runs. `b'a,b,c'.split(b',', 1)` returns `[b'a', b'b,c']`. The fast path for a single-byte separator avoids a Boyer-Moore search.

### `bytes.join`

```c
// CPython: Objects/bytesobject.c:2100 bytes_join
static PyObject *
bytes_join(PyBytesObject *self, PyObject *iterable_of_bytes)
{
    /* Two-pass: first compute total length, then allocate and fill. */
    PyObject *seq = PySequence_Fast(iterable_of_bytes, "...");
    Py_ssize_t seqlen = PySequence_Fast_GET_SIZE(seq);
    Py_ssize_t seplen = PyBytes_GET_SIZE(self);
    /* Compute total */
    Py_ssize_t sz = seplen * (seqlen - 1);
    for (Py_ssize_t i = 0; i < seqlen; i++) sz += PyBytes_GET_SIZE(item[i]);
    PyObject *res = PyBytes_FromStringAndSize(NULL, sz);
    /* Fill */
    char *p = PyBytes_AS_STRING(res);
    for (Py_ssize_t i = 0; i < seqlen; i++) {
        if (i) { memcpy(p, sep, seplen); p += seplen; }
        memcpy(p, PyBytes_AS_STRING(item[i]), itemlen);
        p += itemlen;
    }
    return res;
}
```

`b','.join([b'a', b'b', b'c'])` produces `b'a,b,c'`. The two-pass strategy avoids reallocating as items are accumulated.

### `bytes.decode`

```c
// CPython: Objects/bytesobject.c:2340 bytes_decode
static PyObject *
bytes_decode_impl(PyBytesObject *self, const char *encoding,
                  const char *errors)
{
    return PyUnicode_FromEncodedObject((PyObject *)self, encoding, errors);
}
```

`b'\xc3\xa9'.decode('utf-8')` returns `'\xe9'`. The actual decoding is delegated to the codec registry via `PyUnicode_FromEncodedObject`. The `errors` parameter controls behavior on invalid sequences: `strict`, `replace`, `ignore`, `backslashreplace`.

### `bytes.hex`

```c
// CPython: Objects/bytesobject.c:2420 bytes_hex_impl
static PyObject *
bytes_hex_impl(PyBytesObject *self, PyObject *sep, int bytes_per_sep)
{
    /* Convert each byte to two hex digits. Optional sep inserted every
       bytes_per_sep bytes (positive = from right, negative = from left). */
    const char *buf = PyBytes_AS_STRING(self);
    Py_ssize_t len = PyBytes_GET_SIZE(self);
    return _Py_strhex_with_sep(buf, len, sep, bytes_per_sep);
}
```

`b'\xde\xad\xbe\xef'.hex(':')` returns `'de:ad:be:ef'`. The `bytes_per_sep` argument (default 1) controls grouping. `bytes.fromhex('deadbeef')` is the inverse, implemented in `bytes_fromhex`.

## gopy notes

`bytes.split` is `objects.BytesSplit` in `objects/bytes.go`. The whitespace split uses `strings.Fields` semantics on the raw bytes. `bytes.join` pre-computes total length then uses a single `make([]byte, n)` allocation. `bytes.decode` calls into the codec registry at `module/codecs`. `bytes.hex` uses `hex.EncodeToString` from Go's standard library.
