# `Parser/`

The tokenizer and PEG parser. Source for CPython 3.14 lives at
`cpython/Parser/`. The directory has three layers:

* **`tokenizer/`**: input adapters (file, string, readline, utf-8).
* **`lexer/`**: the state machine that turns characters into tokens.
* **`pegen.c` / `parser.c` / `action_helpers.c`**: the PEG parser
  itself. `parser.c` is generated from `Grammar/python.gram` by
  `Tools/peg_generator/`.

## Reading order

1. [`token.c`](token): the token kind enum and pretty-printer.
2. [`lexer.c`](lexer): the byte-level scanner.
3. [`pegen.c`](pegen): the parser runtime (memo table, error
   recovery, top-level entry).
4. [`action_helpers.c`](action-helpers): AST construction helpers
   invoked from the generated parser.
5. [`parser.c`](parser-generated): the generated PEG state machine.
