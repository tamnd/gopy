# `Lib/string/__init__.py`

<CpyLink path="Lib/string/__init__.py" />

The public `string` module. In CPython 3.14 it moved from a single
`Lib/string.py` to `Lib/string/__init__.py` (alongside the new
`Lib/string/templatelib.py` for PEP 750 template strings). The flat
API is unchanged: character-set constants, `capwords`, `Template`, and
`Formatter`.

`Formatter` delegates its hard parts to the C extension `_string`
(`_string.formatter_parser` for the parse loop,
`_string.formatter_field_name_split` for field-name traversal). The
Python class only adds the override hooks. `Template` compiles a regex
from the `delimiter`/`idpattern`/`braceidpattern` class attributes on
first use via the `_TemplatePattern` descriptor, which means subclass
customisation is free of parse overhead on subsequent calls.

### `Template` pattern compilation (lines 82 to 102)

<CpyLink path="Lib/string/__init__.py" lines="82-102" />

```python
@classmethod
def _compile_pattern(cls):
    import re  # deferred import, for performance
    pattern = cls.__dict__.get('pattern', _TemplatePattern)
    if pattern is _TemplatePattern:
        delim = re.escape(cls.delimiter)
        id = cls.idpattern
        bid = cls.braceidpattern or cls.idpattern
        pattern = fr"""
        {delim}(?:
          (?P<escaped>{delim})  |   # Escape sequence of two delimiters
          (?P<named>{id})       |   # delimiter and a Python identifier
          {{(?P<braced>{bid})}} |   # delimiter and a braced identifier
          (?P<invalid>)             # Other ill-formed delimiter exprs
        )
        """
    if cls.flags is None:
        cls.flags = re.IGNORECASE
    pat = cls.pattern = re.compile(pattern, cls.flags | re.VERBOSE)
    return pat
```

`_compile_pattern` is called by the `_TemplatePattern` descriptor on
first attribute access and by `__init_subclass__` for every subclass.
The four named groups (`escaped`, `named`, `braced`, `invalid`) map
directly to the four branches inside `substitute`'s `convert` closure.
Subclasses change behaviour by overriding `delimiter`, `idpattern`,
`braceidpattern`, or `flags` as class attributes; the compiled regex
is stored back on the subclass so the cost is paid once.

### `Template.substitute` and `safe_substitute` (lines 121 to 161)

<CpyLink path="Lib/string/__init__.py" lines="121-161" />

```python
def substitute(self, mapping=_sentinel_dict, /, **kws):
    if mapping is _sentinel_dict:
        mapping = kws
    elif kws:
        from collections import ChainMap
        mapping = ChainMap(kws, mapping)
    def convert(mo):
        named = mo.group('named') or mo.group('braced')
        if named is not None:
            return str(mapping[named])        # KeyError propagates
        if mo.group('escaped') is not None:
            return self.delimiter
        if mo.group('invalid') is not None:
            self._invalid(mo)
        raise ValueError('Unrecognized named group in pattern', self.pattern)
    return self.pattern.sub(convert, self.template)
```

`substitute` raises `KeyError` for missing keys; `safe_substitute`
wraps the `mapping[named]` lookup in a `try`/`except KeyError` and
returns the original `$name` text instead. The `_sentinel_dict` trick
lets callers use either positional or keyword-only mapping without the
ambiguity of `mapping=None`. When both are provided, a `ChainMap` is
built so keyword args shadow the mapping.

### `Formatter._vformat` (lines 213 to 265)

<CpyLink path="Lib/string/__init__.py" lines="213-265" />

```python
def _vformat(self, format_string, args, kwargs, used_args,
             recursion_depth, auto_arg_index=0):
    if recursion_depth < 0:
        raise ValueError('Max string recursion exceeded')
    result = []
    for literal_text, field_name, format_spec, conversion in \
            self.parse(format_string):
        if literal_text:
            result.append(literal_text)
        if field_name is not None:
            obj, arg_used = self.get_field(field_name, args, kwargs)
            used_args.add(arg_used)
            obj = self.convert_field(obj, conversion)
            format_spec, auto_arg_index = self._vformat(
                format_spec, args, kwargs,
                used_args, recursion_depth-1,
                auto_arg_index=auto_arg_index)
            result.append(self.format_field(obj, format_spec))
    return ''.join(result), auto_arg_index
```

`parse` delegates to `_string.formatter_parser`, a C iterator that
yields `(literal_text, field_name, format_spec, conversion)` tuples.
`_vformat` is called recursively for nested format specs (e.g.
`{value:{width}.{precision}}`), bounded by `recursion_depth` (default 2
from `vformat`). The `auto_arg_index` counter implements the
`{}` auto-numbering mode; mixing auto and manual raises `ValueError`.
`convert_field` handles `!s`, `!r`, and `!a` conversions before
`format_field` calls `format(obj, format_spec)`.
