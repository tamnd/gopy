# `Lib/glob.py`

<CpyLink path="Lib/glob.py" />

`glob` expands a pathname pattern into a list of matching filesystem
paths. It is built on top of `fnmatch` and `os.scandir`/`os.listdir`
and handles three pattern features that `fnmatch` alone does not:
path separators, the `**` recursive wildcard, and `root_dir`/`dir_fd`
anchoring added in Python 3.10.

The public entry point is `glob`; `iglob` is the iterator form that
`glob` wraps. Both accept the same arguments: `pathname` (the pattern),
`root_dir` (an alternative working directory for relative patterns),
`dir_fd` (a directory file descriptor), and `recursive` (enables `**`).

Internally, the pattern is split into a `dirname` / `basename` pair.
Each path segment is tested for magic characters (`*?[`); segments
without magic are resolved as literal names. When `**` is encountered
and `recursive=True`, `glob2` performs a full `os.walk`; otherwise the
segment is treated as a literal `**` directory name.

`iglob` fires two `sys.audit` events — the second carrying `root_dir` and
`dir_fd` — so security-conscious embedders can intercept filesystem
access. The `root_dir` argument is converted to an `os.fspath` string
early; all subsequent `os.listdir` / `os.scandir` calls receive `cwd` as
their directory anchor. When `dir_fd` is set the module uses the
`*at`-family syscalls, which avoids TOCTOU races for trusted callers.

The dispatch table is simple: a literal basename goes to `glob0`, a
pattern basename to `glob1`, and the `**` token to `glob2`. If `dirname`
also contains magic the function recurses, passing `dironly=True` so only
directories are enumerated at intermediate levels. The `dironly` flag is
threaded all the way down to `_iterdir` to avoid `stat` calls on
non-directory entries.

### `glob1` and `glob2` (lines 136 to 190)

<CpyLink path="Lib/glob.py" lines="136-190" />

```python
def glob1(dirname, pattern, dironly):
    if not dirname:
        dirname = os.curdir
    try:
        names = _listdir(dirname, dironly)
    except OSError:
        return []
    if not _ishidden(pattern):
        names = (x for x in names if not _ishidden(x))
    return fnmatch.filter(names, pattern)

def glob2(dirname, pattern, dironly):
    assert _isrecursive(pattern)
    yield pattern[:0]   # b'' or '' depending on type
    yield from _rlistdir(dirname, dironly)
```

`glob1` silently swallows `OSError` from unreadable directories rather
than propagating it, matching historical shell behaviour. Hidden entries
(those starting with `.`) are excluded unless the pattern itself starts
with `.`, implemented by the `_ishidden` predicate. `glob2` yields an
empty string first (representing the current directory match for bare
`**`), then delegates to `_rlistdir` which walks the tree recursively
via `os.scandir`.

### `escape` (lines 211 to 230)

<CpyLink path="Lib/glob.py" lines="211-230" />

```python
_magic_check    = re.compile('([*?[])')
_magic_check_bytes = re.compile(b'([*?[])')

def escape(pathname):
    """Escape all special characters."""
    if isinstance(pathname, bytes):
        match = _magic_check_bytes
    else:
        match = _magic_check
    return match.sub(r'[\1]', pathname)
```

`escape` wraps each magic character inside a `[…]` character class, which
`fnmatch.translate` preserves as a literal. This is the correct approach
because `\*` is not valid in a character class and some regex engines
treat it differently. Both `str` and `bytes` pathnames are handled via
separate pre-compiled regexes to avoid per-call type dispatch overhead.
