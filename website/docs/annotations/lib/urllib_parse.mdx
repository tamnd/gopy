# `Lib/urllib/parse.py`

<CpyLink path="Lib/urllib/parse.py" />

`urllib/parse.py` is the canonical URL manipulation module for CPython.
It implements RFC 3986 parsing, RFC 3986 resolution (joining), and the
`application/x-www-form-urlencoded` encoding format used by HTML forms.
Everything in `urllib.request`, `http.client`, and most third-party HTTP
libraries depends on it.

The module draws a careful line between `str` and `bytes` input. Every
public function accepts both and returns the same type it received.
`_coerce_args` normalizes the handling internally: it detects `bytes`
input, decodes to `str` with `latin-1`, processes as `str`, then
re-encodes the result parts before returning. This round-trip is lossless
for percent-encoded URL components because percent-encoded bytes all fall
in the ASCII range.

The two core parse functions differ in one dimension: `urlparse` treats
the path component for schemes like `http` and `ftp` as having an
optional `;params` suffix (RFC 2396 legacy), while `urlsplit` does not.
All modern callers use `urlsplit`. Both cache their results in a
module-level `_parse_cache` dict keyed by `(urlstring, scheme, allow_fragments)`.

`urlsplit` processes the URL in a single left-to-right pass. Scheme
detection requires the first character of the candidate scheme to be an
ASCII letter (the `url[0] in scheme_chars` guard prevents mistaking a
Windows drive letter like `C:` for a scheme). Netloc extraction only
fires when the remaining URL starts with `//`. Fragment and query
splitting use `str.split(..., 1)` with the appropriate delimiter.
Results are cached in `_parse_cache`; the cache is pruned to
`MAX_CACHE_SIZE = 20` entries by clearing it entirely when it overflows,
which is intentionally simple and avoids the cost of an LRU eviction.

```

`urljoin` implements RFC 3986 Section 5.2 reference resolution. The
priority rules are: if the reference has a scheme that differs from the
base, return the reference as-is. If it has an authority (`netloc`),
remove dot segments from the path and return. Otherwise merge the base
path and reference path, then remove dot segments. `_remove_dot_segments`
implements the RFC 3986 algorithm verbatim, collapsing `.` and `..`
components without touching the authority. The function correctly handles
the edge cases in RFC 3986 Section 5.4 including empty paths, root-relative
references, and paths ending with `/..`.

def quote_from_bytes(bs, safe='/'):
    ...
    safe = _ALWAYS_SAFE.union(safe)
    quoter = _safe_quoters.get(safe)
    if quoter is None:
        _safe_quoters[safe] = quoter = Quoter(safe).__getitem__
    return ''.join([quoter(char) for char in bs])
```

`_ALWAYS_SAFE` holds the 66 unreserved characters that RFC 3986 says
must never be percent-encoded. `quote_from_bytes` first builds a
`safe` set by unioning `_ALWAYS_SAFE` with the caller-supplied safe
characters, then looks up or creates a `Quoter` for that set. `Quoter`
is a `dict` subclass that lazily populates itself: on the first lookup
for a byte value, it checks the safe set and either stores the raw
character or the `%XX` encoding. This means the fast path for
already-safe bytes is a single dict lookup and the slow path pays the
percent-encoding cost exactly once per (byte, safe-set) pair.

### `unquote_to_bytes` and surrogate-escape (lines 901 to 1000)

```python
def unquote_to_bytes(string):
    if not string:
        return b''
    if isinstance(string, str):
        string = string.encode('utf-8')
    bits = string.split(b'%')
    if len(bits) == 1:
        return string
    res = [bits[0]]
    append = res.append
    for item in bits[1:]:
        try:
            append(bytes([int(item[:2], 16)]))
            append(item[2:])
        except (ValueError, IndexError):
            append(b'%')
            append(item)
    return b''.join(res)

def unquote(string, encoding='utf-8', errors='replace'):
    ...
    return unquote_to_bytes(string).decode(encoding, errors)
```

`unquote_to_bytes` splits on `%` and interprets each two-character hex
sequence that follows. Malformed sequences (not two hex digits, or `%`
at the end of the string) are passed through unchanged, preserving
round-trip fidelity for inputs that contain literal `%` characters.
`unquote` decodes the resulting bytes with the given encoding; the
default `errors='replace'` substitutes the Unicode replacement character
`U+FFFD` for byte sequences that are not valid UTF-8, which is the safe
choice for URLs received from external sources. For internal round-trips
where the original encoding is known, callers can pass `errors='surrogatepass'`
to preserve byte values outside the BMP.
