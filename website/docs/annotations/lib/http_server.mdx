# `Lib/http/server.py`

<CpyLink path="Lib/http/server.py" />

`http/server.py` implements the server side of HTTP/1.1 on top of
`socketserver.TCPServer`. It provides three concrete handler classes at
different levels of abstraction: `BaseHTTPRequestHandler` for raw method
dispatch, `SimpleHTTPRequestHandler` for serving a directory tree, and
`CGIHTTPRequestHandler` for executing legacy CGI scripts.

`HTTPServer` is a thin `TCPServer` subclass that sets
`allow_reuse_address = True`. `ThreadingHTTPServer` adds `ThreadingMixIn`
to handle each request in its own thread. The server classes themselves
hold almost no logic; all HTTP behaviour lives in the handler.

`BaseHTTPRequestHandler` reads one request line per connection keep-alive
cycle. `handle()` loops calling `handle_one_request()` as long as the
connection is kept alive. `handle_one_request` reads the request line,
calls `parse_request()` to split the method, path, and HTTP version,
then dispatches to `do_METHOD()` on the handler subclass. The response
side provides `send_response`, `send_header`, and `end_headers` to build
well-formed HTTP/1.1 responses without manual string assembly.

`SimpleHTTPRequestHandler` maps URL paths to the local filesystem via
`translate_path`, serves file contents with correct `Content-Type` from
`mimetypes`, generates HTML directory listings, and respects
`If-Modified-Since` for conditional GET.

```python
def handle_one_request(self):
    try:
        self.raw_requestline = self.rfile.readline(65537)
        if len(self.raw_requestline) > 65536:
            self.requestline = ''
            self.request_version = ''
            self.command = ''
            self.send_error(HTTPStatus.REQUEST_URI_TOO_LONG)
            return
        if not self.raw_requestline:
            self.close_connection = True
            return
        if not self.parse_request():
            return
        mname = 'do_' + self.command
        if not hasattr(self, mname):
            self.send_error(HTTPStatus.NOT_IMPLEMENTED, ...)
            return
        method = getattr(self, mname)
        method()
        self.wfile.flush()
    except TimeoutError as e:
        self.log_error("Request timed out: %r", e)
        self.close_connection = True
```

`handle_one_request` enforces a hard 65536-byte limit on the request
line before even attempting to parse it, sending a `431` error if
exceeded. After parsing, method dispatch is purely reflective: it looks
up `do_GET`, `do_POST`, and so on via `getattr`. Unknown methods yield
`501 Not Implemented`. Each handler method is responsible for sending its
own complete response; `handle_one_request` only calls `wfile.flush()`
afterward.

```python
def send_response(self, code, message=None):
    if self.request_version != 'HTTP/0.9':
        if message is None:
            if code in self.responses:
                message = self.responses[code][0]
            else:
                message = ''
        if not hasattr(self, '_headers_buffer'):
            self._headers_buffer = []
        self._headers_buffer.append(("%s %d %s\r\n" %
                                     (self.protocol_version, code, message))
                                    .encode("latin-1", "strict"))
    if self.server_version:
        self.send_header('Server', self.version_string())
    self.send_header('Date', self.date_time_string())

def send_header(self, keyword, value):
    if self.request_version != 'HTTP/0.9':
        if not hasattr(self, '_headers_buffer'):
            self._headers_buffer = []
        self._headers_buffer.append(
            ("%s: %s\r\n" % (keyword, value)).encode("latin-1", "strict"))
    if keyword.lower() == 'connection':
        if value.lower() == 'close':
            self.close_connection = True
        elif value.lower() == 'keep-alive':
            self.close_connection = False

def end_headers(self):
    if self.request_version != 'HTTP/0.9':
        self._headers_buffer.append(b"\r\n")
        self.flush_headers()
```

Headers are accumulated in `_headers_buffer` rather than written to the
socket immediately. `end_headers` appends the blank line that terminates
the header section and then calls `flush_headers()` to write the entire
buffer in one `wfile.write` call, reducing the number of TCP segments.
`send_header` also inspects the `Connection` header value to update
`self.close_connection`, which controls whether `handle()` will loop for
a subsequent request on the same connection.

```python
def log_message(self, format, *args):
    sys.stderr.write("%s - - [%s] %s\n" %
                     (self.address_string(),
                      self.log_date_time_string(),
                      format % args))

def log_date_time_string(self):
    now = time.time()
    year, month, day, hh, mm, ss, x, y, z = time.localtime(now)
    s = "%02d/%3s/%04d %02d:%02d:%02d" % (
        day, self.monthname[month], year, hh, mm, ss)
    return s

def address_string(self):
    return self.client_address[0]
```

All logging goes to `sys.stderr` in Combined Log Format. `log_message`
is the single override point: subclasses replace it to redirect logs to
a file or structured logger. `address_string` returns just the client IP
by default; in older versions it called `socket.getfqdn`, which could
block on a reverse DNS lookup for every request. The current
implementation avoids that latency by returning the raw address string,
leaving DNS resolution to the caller if needed.
