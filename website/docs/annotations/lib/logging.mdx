# `Lib/logging/__init__.py`

<CpyLink path="Lib/logging/__init__.py" />

The entire core logging framework lives in this one file (~2300 lines).
Unlike `asyncio` or `unittest`, there is no separate package structure:
`Lib/logging/__init__.py` contains `Logger`, `Handler`, `Formatter`,
`LogRecord`, `Manager`, `Filter`, `Filterer`, and `basicConfig` all in
one place. The companion files `Lib/logging/handlers.py` and
`Lib/logging/config.py` add optional extras (rotating file handlers,
`dictConfig`) but are not imported by the core.

The central abstraction is the `Logger` hierarchy. Logger names are
dotted strings: `"a.b.c"` has parent `"a.b"`, which has parent `"a"`,
which has parent the root logger (`logging.root`). The `Manager` object
maintains a flat `loggerDict` mapping names to `Logger` instances or
`PlaceHolder` sentinels (for intermediate names that have no logger yet).
When a `Logger` emits a record, `callHandlers` walks up the parent chain
and calls `handle()` on every attached `Handler` until it reaches a
logger with `propagate = False` or the root.

Level filtering is intentionally cheap. Each `Logger` has an integer
`level` field (default `NOTSET = 0`, which means "defer to parent").
`Logger.isEnabledFor(level)` calls `getEffectiveLevel()`, which walks
the parent chain once to find the first non-zero level, then compares.
This is the only path for the common case where the log call is below the
threshold and nothing should happen.

### `Logger` hierarchy and `callHandlers` (lines 1051 to 1450)

<CpyLink path="Lib/logging/__init__.py" lines="1051-1450" />

```python
def callHandlers(self, record):
    c = self
    found = 0
    while c:
        for hdlr in c.handlers:
            found = found + 1
            if record.levelno >= hdlr.level:
                hdlr.handle(record)
        if not c.propagate:
            c = None    # break out
        else:
            c = c.parent
    if (found == 0):
        if lastResort:
            if record.levelno >= lastResort.level:
                lastResort.handle(record)
        elif raiseExceptions and not self.manager.emittedNoHandlerWarning:
            sys.stderr.write("No handlers could be found for logger"
                             " \"%s\"\n" % self.name)
            self.manager.emittedNoHandlerWarning = True
```

`callHandlers` walks the `c.parent` chain. Each `Logger` in the chain
may have zero or more `Handler` objects attached. Every handler whose
`level` is at or below the record's `levelno` gets a call to
`hdlr.handle(record)`. Walking continues up the chain unless `c.propagate`
is `False`.

If the walk completes without finding any handler (including the root
logger), the framework falls back to `lastResort`, a `_StderrHandler`
at `WARNING` level. This is the behavior that produces the
`"No handlers could be found"` message in Python 2; in Python 3 it is
replaced by silently writing to `sys.stderr` via `lastResort`.

The parent chain is built by `Manager._fixupParents`. Each time a new
`Logger` is created, `_fixupParents` scans `loggerDict` for the closest
ancestor and sets `logger.parent` directly. This means parent traversal
at emit time is a pointer walk with no dict lookups.

```python
class LogRecord:
    def __init__(self, name, level, pathname, lineno,
                 msg, args, exc_info, func=None, sinfo=None):
        ct = time.time()
        self.name = name
        self.msg = msg
        self.args = args
        self.levelname = getLevelName(level)
        self.levelno = level
        self.pathname = pathname
        ...
        self.lineno = lineno
        self.funcName = func
        self.created = ct
        self.msecs = round((ct - int(ct)) * 1000)
        self.relativeCreated = (self.created - _startTime) * 1000
        self.thread = threading.get_ident()
        self.process = os.getpid()
        ...
```

`LogRecord.__init__` captures everything needed to format the message
later. `msg` and `args` are stored separately (not yet interpolated)
so that handlers can skip formatting entirely for filtered records.
`getMessage()` performs the `msg % args` interpolation on demand:

```python
def getMessage(self):
    msg = str(self.msg)
    if self.args:
        msg = msg % self.args
    return msg
```

`exc_info` is stored as-is (the `(type, value, traceback)` triple
returned by `sys.exc_info()`). `Formatter.formatException` converts it
to a string by calling `traceback.print_exception` only when formatting,
not at record creation time.

`Logger._log` is the single point that constructs `LogRecord`:

```python
def _log(self, level, msg, args, **kwargs):
    ...
    record = self.makeRecord(self.name, level, fn, lno, msg, args, exc_info, func, extra, sinfo)
    self.handle(record)
```

`makeRecord` can be overridden by subclasses to produce custom record
types. The default calls `LogRecord(...)` directly.

### `Formatter.format` (lines 351 to 550)

<CpyLink path="Lib/logging/__init__.py" lines="351-550" />

```python
class Formatter:
    def format(self, record):
        record.message = record.getMessage()
        if self.usesTime():
            record.asctime = self.formatTime(record, self.datefmt)
        s = self.formatMessage(record)
        if record.exc_info:
            if not record.exc_text:
                record.exc_text = self.formatException(record.exc_info)
        if record.exc_text:
            if s[-1:] != "\n":
                s = s + "\n"
            s = s + record.exc_text
        if record.stack_info:
            if s[-1:] != "\n":
                s = s + "\n"
            s = s + self.formatStack(record.stack_info)
        return s
```

`Formatter.format` uses `%`-style string interpolation via
`formatMessage`, which calls `self._style.format(record)`. Three style
objects exist: `PercentStyle` (`%`), `StrFormatStyle` (`{`), and
`StringTemplateStyle` (`$`). The style is chosen by the `style` argument
to `Formatter.__init__`.

Exception formatting is lazy and cached: `record.exc_text` is `None`
until the first format call, then set to the formatted traceback string.
Subsequent calls to `format` on the same record skip
`formatException` entirely.

`formatTime` produces the `asctime` field using `time.strftime`. The
default `datefmt` is `None`, which maps to ISO 8601-ish
`"2003-07-08 16:49:45,896"` (the comma before milliseconds is
deliberate and is documented behavior).

```python
def basicConfig(**kwargs):
    _acquireLock()
    try:
        force = kwargs.pop('force', False)
        encoding = kwargs.pop('encoding', None)
        errors = kwargs.pop('errors', 'backslashreplace')
        if force:
            for h in root.handlers[:]:
                root.removeHandler(h)
                h.close()
        if len(root.handlers) == 0:
            handlers = kwargs.pop('handlers', None)
            ...
            if handlers is None:
                filename = kwargs.pop('filename', None)
                mode = kwargs.pop('mode', 'a')
                if filename:
                    h = FileHandler(filename, mode, encoding=encoding, errors=errors)
                else:
                    stream = kwargs.pop('stream', None)
                    h = StreamHandler(stream)
                handlers = [h]
            ...
            fs = kwargs.pop('format', BASIC_FORMAT)
            dfs = kwargs.pop('datefmt', None)
            style = kwargs.pop('style', '%')
            fmt = Formatter(fs, dfs, style)
            for handler in handlers:
                ...
                handler.setFormatter(fmt)
                root.addHandler(handler)
            level = kwargs.pop('level', None)
            if level is not None:
                root.setLevel(level)
    finally:
        _releaseLock()
```

`basicConfig` is the one-call setup most scripts use. It is guarded by
`_acquireLock()` (a `threading.RLock`) so it is safe to call from
multiple threads at startup. The idempotency check (`len(root.handlers) == 0`)
means a second call is a no-op unless `force=True` is passed.

The precedence is: caller-supplied `handlers` list first; then a named
`filename`; then a `stream` (defaulting to `sys.stderr`). Only one of
`handlers`, `filename`, and `stream` may be specified; passing more than
one raises `ValueError`. After attaching handlers, `basicConfig` sets
the root level if `level=` was given, leaving it at `WARNING` otherwise.
