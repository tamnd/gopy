# `Lib/textwrap.py`

<CpyLink path="Lib/textwrap.py" />

Pure-Python text-wrapping library. The file exports one class
(`TextWrapper`) and five module-level functions (`wrap`, `fill`,
`shorten`, `dedent`, `indent`). Everything goes through `TextWrapper`
internally; the module-level functions are thin constructors that build
a wrapper, call one method, and return.

`TextWrapper` is parameterised by thirteen attributes set in
`__init__`. Two regex objects are compiled at class definition time and
shared across all instances: `wordsep_re` for hyphen-aware splitting
and `wordsep_simple_re` for whitespace-only splitting. The wrapping
pipeline is: munge whitespace, split into chunks, optionally fix
sentence endings, fill chunks greedily into lines.

### Chunk splitting regex (lines 74 to 103)

<CpyLink path="Lib/textwrap.py" lines="74-103" />

```python
word_punct = r'[\w!"\'&.,?]'
letter = r'[^\d\W]'
whitespace = r'[%s]' % re.escape(_whitespace)
nowhitespace = '[^' + whitespace[1:]
wordsep_re = re.compile(r'''
    ( # any whitespace
      %(ws)s+
    | # em-dash between words
      (?<=%(wp)s) -{2,} (?=\w)
    | # word, possibly hyphenated
      %(nws)s+? (?:
        # hyphenated word
          -(?: (?<=%(lt)s{2}-) | (?<=%(lt)s-%(lt)s-))
          (?= %(lt)s -? %(lt)s)
        | # end of word
          (?=%(ws)s|\z)
        | # em-dash
          (?<=%(wp)s) (?=-{2,}\w)
        )
    )''' % {'wp': word_punct, 'lt': letter,
            'ws': whitespace, 'nws': nowhitespace},
    re.VERBOSE)
```

`wordsep_re` is the complex path used when `break_on_hyphens=True`. It
keeps hyphens attached to their left-hand syllable so that
`goof-ball` produces `['goof-', 'ball']`. The three-branch alternation
handles whitespace runs, em-dashes between words, and compound-hyphen
words. When `break_on_hyphens=False`, `wordsep_simple_re` is used
instead: it only splits on whitespace, leaving hyphenated words intact.
Both regexes are compiled once at class definition, not per instance.

```python
def _wrap_chunks(self, chunks):
    lines = []
    if self.width <= 0:
        raise ValueError("invalid width %r (must be > 0)" % self.width)
    chunks.reverse()          # work from the end so pop() is O(1)
    while chunks:
        cur_line = []
        cur_len = 0
        indent = self.subsequent_indent if lines else self.initial_indent
        width = self.width - len(indent)
        if self.drop_whitespace and chunks[-1].strip() == '' and lines:
            del chunks[-1]
        while chunks:
            l = len(chunks[-1])
            if cur_len + l <= width:
                cur_line.append(chunks.pop())
                cur_len += l
            else:
                break
        if chunks and len(chunks[-1]) > width:
            self._handle_long_word(chunks, cur_line, cur_len, width)
        ...
        if cur_line:
            lines.append(indent + ''.join(cur_line))
    return lines
```

Chunks are reversed so `pop()` is O(1). Each pass through the outer
loop starts a new output line; each pass through the inner loop packs
chunks until the line is full. `drop_whitespace` strips leading
whitespace chunks from all lines except the first. When `max_lines` is
set, the loop terminates early and appends `placeholder` (default
`' [...]'`) to the last line, backing off words until it fits.

### `dedent` (lines 416 to 444)

<CpyLink path="Lib/textwrap.py" lines="416-444" />

```python
def dedent(text):
    lines = text.split('\n')
    non_blank_lines = [l for l in lines if l and not l.isspace()]
    l1 = min(non_blank_lines, default='')
    l2 = max(non_blank_lines, default='')
    margin = 0
    for margin, c in enumerate(l1):
        if c != l2[margin] or c not in ' \t':
            break
    return '\n'.join([l[margin:] if not l.isspace() else '' for l in lines])
```

`dedent` exploits the property that the common prefix of all lines is
bounded by the lexicographic minimum (`l1`) and maximum (`l2`). Walking
`l1` and comparing against the same position in `l2` finds the first
column where they diverge or where the character is not a space or tab.
That column is `margin`. Entirely blank lines are normalised to `''`
rather than stripped to preserve paragraph structure.

### `indent` (lines 447 to 469)

<CpyLink path="Lib/textwrap.py" lines="447-469" />

```python
def indent(text, prefix, predicate=None):
    prefixed_lines = []
    if predicate is None:
        for line in text.splitlines(True):
            if not line.isspace():
                prefixed_lines.append(prefix)
            prefixed_lines.append(line)
    else:
        for line in text.splitlines(True):
            if predicate(line):
                prefixed_lines.append(prefix)
            prefixed_lines.append(line)
    return ''.join(prefixed_lines)
```

`indent` uses `splitlines(True)` to preserve line endings exactly.
Without a predicate, `isspace()` guards the prefix insertion so that
blank lines (including lines containing only `\n`) are not indented.
The two code paths duplicate the loop body rather than calling
`predicate` unconditionally because the inline `isspace()` check
measures roughly 30% faster on typical text.
