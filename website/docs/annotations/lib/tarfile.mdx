# `Lib/tarfile.py`

<CpyLink path="Lib/tarfile.py" />

The TAR archive implementation. The module handles three on-disk formats:
POSIX ustar (the default, portable subset), GNU tar (long names, sparse
files), and PAX (POSIX.1-2001, arbitrary Unicode metadata via keyword
records). Compression is layered on top through the `_Stream` class, which
wraps gzip, bz2, lzma, and (in 3.14) zstd.

The public API centers on two classes. `TarInfo` represents one archive
member: name, size, mtime, mode, type, linkname, uid/gid, uname/gname,
devmajor/devminor, and a `pax_headers` dict for PAX keyword records.
`TarFile` owns the underlying file descriptor and exposes `add`, `addfile`,
`extract`, `extractall`, `getmember`, `getmembers`, `getnames`, and the
`open` factory.

The `open` factory dispatches on the mode string: `"r"` auto-detects
compression, `"r:gz"` / `"w:bz2"` / `"r|xz"` select a specific
compressor (pipe `|` means streaming, colon `:` allows seeking).
`"r:*"` also auto-detects.

Security filtering was tightened significantly in 3.12 and extended in
3.14. `extractall` accepts a `filter` keyword accepting `"data"`,
`"tar"`, or `"fully_trusted"` presets, or a callable. The `"data"`
preset blocks absolute paths, `..` components, special files, and
high-privilege mode bits.


`_Stream` is the compression shim. In write mode it wraps a compressor
object (`zlib.compressobj`, `bz2.BZ2Compressor`, `lzma.LZMACompressor`,
or `zstd.ZstdCompressor`) and flushes compressed bytes to the underlying
file object in `bufsize`-sized chunks. In read mode it holds the
corresponding decompressor and refills an internal buffer on demand. The
`pos` attribute tracks the logical uncompressed position and is used to
implement `seek` by decompressing from the start. Pipe-mode archives
(mode `"r|"` or `"w|"`) set `seekable = False` and raise on any attempt
to seek backward.

### Parsing a header block: `TarInfo.frombuf` (lines 521 to 750)

<CpyLink path="Lib/tarfile.py" lines="521-750" />

```python
@classmethod
def frombuf(cls, buf, encoding, errors):
    if len(buf) == 0:
        raise EmptyHeaderError("empty header")
    if len(buf) != BLOCKSIZE:
        raise TruncatedHeaderError("truncated header")
    if buf.count(NUL) == BLOCKSIZE:
        raise EOFHeaderError("end of file header")

    chksum = nti(buf[148:156])
    if chksum not in calc_chksums(buf[:148] + bytes(8) + buf[156:]):
        raise InvalidHeaderError("bad checksum")

    obj = cls()
    obj.name   = nts(buf[0:100],   encoding, errors)
    obj.mode   = nti(buf[100:108]) & 0o7777
    obj.uid    = nti(buf[108:116])
    obj.gid    = nti(buf[116:124])
    obj.size   = nti(buf[124:136])
    obj.mtime  = nti(buf[136:148])
    obj.type   = buf[156:157]
    obj.linkname = nts(buf[157:257], encoding, errors)
    obj.uname  = nts(buf[265:297],  encoding, errors)
    obj.gname  = nts(buf[297:329],  encoding, errors)
    ...
    # POSIX magic: "ustar\0" or "ustar  \0"
    if buf[257:265] in (POSIX_MAGIC, GNU_MAGIC):
        obj.devmajor = nti(buf[329:337])
        obj.devminor = nti(buf[337:345])
    return obj
```

Every TAR member starts with a 512-byte header block. `nts` decodes a
null-terminated byte string; `nti` decodes an octal ASCII integer (with a
special case for GNU base-256 encoding when the field starts with
`\x80`). After the basic ustar fields, `frombuf` checks the magic bytes
to distinguish ustar from GNU format and then calls the appropriate
`_proc_*` method to handle long names, PAX keyword records, or sparse
maps that occupy additional blocks.

### Writing members: `addfile` (lines 1601 to 1800)

<CpyLink path="Lib/tarfile.py" lines="1601-1800" />

```python
def addfile(self, tarinfo, fileobj=None):
    self._check("awx")
    tarinfo = copy.copy(tarinfo)
    buf = tarinfo.tobuf(self.format, self.encoding, self.errors)
    self.fileobj.write(buf)
    self.offset += len(buf)
    bufsize = self.copybufsize
    if fileobj is not None:
        copyfileobj(fileobj, self.fileobj, tarinfo.size, bufsize=bufsize)
        blocks, remainder = divmod(tarinfo.size, BLOCKSIZE)
        if remainder > 0:
            self.fileobj.write(NUL * (BLOCKSIZE - remainder))
            blocks += 1
        self.offset += blocks * BLOCKSIZE
    self.members.append(tarinfo)
```

`addfile` is the single write primitive. It serialises `tarinfo` to
bytes via `tobuf` (which may emit one or more PAX or GNU extension blocks
before the data header), writes them, then streams `fileobj` in chunks.
TAR requires every data region to be padded to a multiple of 512 bytes,
so the remainder is filled with NUL bytes. The caller is responsible for
setting `tarinfo.size` correctly before calling `addfile`; there is no
seek-back to patch the size field after writing.

```python
def _data_filter(member, dest_path):
    # Absolute paths
    if os.path.isabs(member.name):
        raise AbsolutePathError(member)
    # Path traversal
    if os.path.isabs(member.name) or ".." in member.name.split("/"):
        raise OutsideDestinationError(member, path)
    # Special file types
    if member.isdev():
        raise SpecialFileError(member)
    if member.issym() and _symlink_from_resolved_to_outside(member, dest_path):
        raise LinkOutsideDestinationError(member)
    # Dangerous mode bits
    if member.mode & (stat.S_ISUID | stat.S_ISGID):
        member = copy.copy(member)
        member.mode &= ~(stat.S_ISUID | stat.S_ISGID)
    # World-writable sticky directories are kept but warned
    ...
    return member
```

Three preset filters are provided. `fully_trusted_filter` is a no-op
passthrough that restores pre-3.12 behaviour. `tar_filter` blocks absolute
paths and `..` traversals but allows device files. `data_filter` applies
the strictest checks: it also rejects device files, rejects symlinks that
escape the destination tree, and strips setuid/setgid bits. Callers pass
the filter to `extractall(filter=...)` or set `TarFile.extraction_filter`
as a class-level default. A custom filter is a callable that receives a
`TarInfo` and the resolved destination path and either returns a
(possibly modified) `TarInfo` or raises to skip the member.
