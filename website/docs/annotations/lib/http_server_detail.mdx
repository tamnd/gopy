# Lib/http/server.py

<CpyLink path="Lib/http/server.py" />

The file assembles a working HTTP/1.x server from three layers. At the
bottom, `HTTPServer` subclasses `socketserver.TCPServer` and adds
`server_name`/`server_port` storage. In the middle,
`BaseHTTPRequestHandler` handles one request at a time: it parses the
request line and headers, dispatches to a `do_<COMMAND>` method, and
provides the `send_response`/`send_header`/`end_headers` trio for building
responses. At the top, `SimpleHTTPRequestHandler` maps URL paths to the
local filesystem and generates directory listings. A `ThreadingHTTPServer`
mixin and a `test()` function complete the module; the `__main__` block
wires them to argparse so the module doubles as `python -m http.server`.

`allow_reuse_address = True` lets the server restart immediately after a
crash without waiting out `TIME_WAIT`. `daemon_threads = True` means
in-flight request threads do not block interpreter shutdown.

```python
        self.close_connection = True
        requestline = str(self.raw_requestline, 'iso-8859-1')
        requestline = requestline.rstrip('\r\n')
        self.requestline = requestline
        words = requestline.split()
        if len(words) == 0:
            return False

        if len(words) >= 3:  # Enough to determine protocol version
            version = words[-1]
            try:
                if not version.startswith('HTTP/'):
                    raise ValueError
```

```python
# CPython: Lib/http/server.py:580 BaseHTTPRequestHandler.send_header
    def send_header(self, keyword, value):
        """Send a MIME header to the headers buffer."""
        if self.request_version != 'HTTP/0.9':
            if not hasattr(self, '_headers_buffer'):
                self._headers_buffer = []
            self._headers_buffer.append(
                ("%s: %s\r\n" % (keyword, value)).encode('latin-1', 'strict'))

        if keyword.lower() == 'connection':
            if value.lower() == 'close':
                self.close_connection = True
            elif value.lower() == 'keep-alive':
                self.close_connection = False

# CPython: Lib/http/server.py:594 BaseHTTPRequestHandler.end_headers
    def end_headers(self):
        """Send the blank line ending the MIME headers."""
        if self.request_version != 'HTTP/0.9':
            self._headers_buffer.append(b"\r\n")
            self.flush_headers()
```

Headers accumulate in `_headers_buffer` as encoded bytes and are written
to `wfile` in a single `b"".join(...)` call in `flush_headers`. Nothing
touches the socket until `end_headers` is called.

## gopy notes

gopy has no HTTP server module planned for current milestone work; this
file is annotated for reference. A Go port would map `HTTPServer` to a
`net/http`-backed struct, replace the `socketserver.StreamRequestHandler`
machinery with a `http.Handler` implementation, and re-express
`BaseHTTPRequestHandler`'s header buffer as a `bufio.Writer`. The
`SimpleHTTPRequestHandler` filesystem logic translates directly to
`http.FileServer` with a custom `http.Dir` root. The `test()` function
has a direct Go analogue in `http.ListenAndServe`.
