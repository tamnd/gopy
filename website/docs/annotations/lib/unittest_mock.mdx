# `Lib/unittest/mock.py`

<CpyLink path="Lib/unittest/mock.py" />

`unittest.mock` is the standard-library mocking framework. Its core
abstraction is `NonCallableMock`, a proxy object that records every
attribute access and method call made on it. `Mock` and `MagicMock` add
callability and automatic magic-method configuration on top of that base.

The class hierarchy is deliberately layered. `NonCallableMock` holds all
the state: `_mock_children` (child mocks created on attribute access),
`_mock_call_args_list`, `_mock_called`, and the optional `spec`. `CallableMixin`
adds `__call__` and the three internal call-recording methods. `Mock` inherits
from both in MRO order. `MagicMock` adds `MagicMixin` which pre-populates all
dunder methods (`__iter__`, `__len__`, `__add__`, etc.) so that magic-method
dispatch, which bypasses `__getattr__`, still routes through the mock.

`patch` is a decorator and context manager that replaces a named attribute
in a module's namespace for the duration of a test and restores it afterward.
It delegates to `_patch`, which records the original value in `self.temp_original`
and uses `setattr`/`delattr` to perform the swap in `__enter__` and the
restore in `__exit__`. `patch.object`, `patch.dict`, and `patch.multiple`
are alternative entry points that share the same restoration protocol.

`create_autospec` introspects a live object using `inspect` and builds a
spec-constrained mock whose attribute accesses and call signatures mirror
those of the original. Calling a mock created from a function with the
wrong number of arguments raises `TypeError`, enabling API contract
testing without invoking the real implementation.

```python
def __getattr__(self, name):
    if name in {'_mock_methods', '_mock_unsafe'}:
        raise AttributeError(name)
    elif self._mock_methods is not None:
        if name not in self._mock_methods or name.startswith('_'):
            raise AttributeError("Mock object has no attribute %r" % name)
    elif _all_magics(name):
        raise AttributeError(name)

    if not self._mock_unsafe and (not self._mock_methods or
            name not in self._mock_methods):
        if name.startswith(('assert', 'assret', 'asert', 'aseert', 'assrt')):
            raise AttributeError(
                f"{name!r} is not a supported mock method.")

    result = self._mock_children[name]
    if result is _deleted:
        raise AttributeError(name)
    elif result is None:
        wraps = None
        if self._mock_wraps is not None:
            wraps = getattr(self._mock_wraps, name)
        return self._get_child_mock(
            parent=self, name=name, wraps=wraps, _new_name=name,
            _new_parent=self
        )
    return result
```

Every attribute lookup on a `NonCallableMock` that does not resolve
through `object.__getattribute__` reaches `__getattr__`. If the name is
not already in `_mock_children` a new child mock is created via
`_get_child_mock` and cached. The typo guard (lines that check for
`assert`, `assret`, etc.) catches the common mistake of writing
`mock.assert_called()` when the method is actually `mock.assert_called_with()`;
without this guard the typo silently creates a child mock and the
assertion is never made, leading to false-passing tests.

```python
    if not self.call_count == 1:
        msg = ("Expected '%s' to be called once. Called %s times.%s"
               % (self._mock_name or 'mock',
                  self.call_count,
                  self._calls_repr()))
        raise AssertionError(msg)
    return self.assert_called_with(*args, **kwargs)

def assert_any_call(self, /, *args, **kwargs):
    expected = self._call_matcher(_Call((args, kwargs), two=True))
    cause = expected if isinstance(expected, Exception) else None
    matches = [c for c in self.call_args_list
               if self._call_matcher(c) == expected]
    if not matches:
        expected_string = self._format_mock_call_signature(args, kwargs)
        raise AssertionError(
            '%s call not found' % expected_string) from cause
```

`assert_called_with` checks only the most recent call (via `call_args`);
`assert_called_once_with` additionally enforces that the mock was called
exactly once. `assert_any_call` scans the entire `call_args_list`, making
it appropriate when the order or number of calls is irrelevant but a
specific invocation must have occurred. All three route through
`_call_matcher`, which applies a `spec`-derived signature to normalise
positional and keyword arguments before comparison, so
`mock(1, b=2)` and `mock(a=1, b=2)` match when the spec says the first
parameter is named `a`.

```python
def __exit__(self, *exc_info):
    if self.is_local and self.temp_original is not DEFAULT:
        setattr(self.getter(), self.attribute, self.temp_original)
    elif not self.is_local:
        delattr(self.getter(), self.attribute)
    ...
```

`__enter__` calls `get_original()` to resolve the target using
`getattr(target, attribute)` and records whether the attribute existed
locally on the object (`is_local`) or was inherited. If no replacement
was specified (`new is DEFAULT`) a fresh `MagicMock` is auto-created with
`spec=original` so that the mock mirrors the replaced object's API.
`__exit__` restores the original: if the attribute was local it uses
`setattr`, if it was inherited it uses `delattr` so the original
inherited value becomes visible again rather than shadowing it with the
saved copy. Stacked `@patch` decorators are applied in reverse MRO order
(innermost last in the argument list) because each decorator wraps the
previous one.

`create_autospec` uses `inspect.signature` to attach the real function
signature to each method mock, so argument-count errors are caught at
test time rather than silently swallowed. When `spec` is a class and
`instance=False`, the returned mock behaves like the class itself (i.e.,
it is callable and returns an instance mock). When `instance=True`, the
mock behaves like an instance of the class. The recursive walk ensures
that nested attributes are also spec-constrained rather than being plain
auto-created child mocks, which would permit any attribute access on them.
