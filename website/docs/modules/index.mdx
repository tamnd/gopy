# Modules

gopy ships a subset of CPython's built-in and standard-library modules.
Built-in modules are Go ports under `module/`. Pure-Python stdlib files
live under `stdlib/`.

## Built-in

* [`sys`](sys)
* [`builtins`](builtins)

* [`os`](os)
* [`functools`](functools)
