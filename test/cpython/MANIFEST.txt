# gopy test corpus manifest

# One row per entry under CPython 3.14's Lib/test/. Format:
#
#   name<TAB>status<TAB>version<TAB>note (optional)
#
# Status values:
#
#   done          test runs green under the gopy harness; pinned in CI
#   ready         feature shipped; test expected to pass once vendored
#   pending       vendored but has known divergences; runner skips
#   deferred      feature has not shipped yet (typically stdlib gap)
#   out-of-scope  CPython internals gopy will not carry
#
# Version names the gopy release that owns the underlying feature.
# Empty (just a tab placeholder) for out-of-scope entries.
#
# A trailing "/" on the name marks a Lib/test/test_X/ package
# (sub-suite) rather than a flat test_X.py file.
#
# Source of truth for the triage rationale: ~/notes/Spec/1700/.
# Whenever a row's status changes, update the spec too.
