# v0.0.0 - 2026-05-04

The first tagged release. This version is project scaffolding only. The
interpreter does not run Python code yet.

## Added

* Go module `github.com/tamnd/gopy` targeting Go 1.24+.
* `cmd/gopy` entry point with `--version` and `--copyright` flags.
* `build` package with `Version`, `PythonCompatVersion`, `Platform`,
  `Compiler`, `VersionString`, and `Copyright` symbols. Mirrors the
  CPython getversion / getplatform / getcompiler / getcopyright files.
* Apache License 2.0.
* `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`.
* GitHub Actions workflows for CI (build, vet, lint, test on Linux,
  macOS, Windows) and tag-driven releases (multi-platform binaries via
  GoReleaser, checksums, attestations).
* Dependabot configuration for Go modules and GitHub Actions.
* `.golangci.yml`, `.editorconfig`, `.gitattributes`, `.gitignore`.
* Issue and pull-request templates.

## Compatibility

* Go: 1.24 or newer.
* CPython behavioural target: 3.14.0+.

## Known limitations

* No parser, compiler, VM, or standard library yet. Subsequent releases
  add these in the order described in the project roadmap.
