# v0.4.0 - 2026-05-04

Strings, numbers, hashing, and the format-spec mini-language. After
v0.4 a Go caller can parse and format every Python numeric literal,
hash bytes under the runtime secret, and render values via the
`format()` mini-language byte-for-byte against CPython 3.14.

## Shipped

### `pystrconv/`

Locale-independent string and number conversion. Ports
`pyctype.c`, `pystrcmp.c`, `mystrtoul.c`, `pystrhex.c`, `pystrtod.c`,
and (the wrapper for) `dtoa.c`.

* `Flags`, `IsLower/Upper/Alpha/Digit/XDigit/Alnum/Space`, `ToLower`,
  `ToUpper`. Computed (not table-driven); 0..255 round-trip verified.
* `CompareInsensitive`, `CompareInsensitiveN` ASCII case-fold compare.
* `Hex`, `HexBytes`, `HexWithSep`, `HexBytesWithSep` for `bytes.hex`.
* `ParseUint`, `ParseInt` with base 0 autodetect (`0x`, `0o`, `0b`),
  bases 2..36, leading whitespace, sign, and overflow detection.
* `ParseFloat` over Go's `strconv` with CPython preprocessing:
  rejects `nan(payload)`, accepts PEP 515 underscores, treats
  `inf`/`infinity` case-insensitively. Bit-for-bit IEEE-754 parity.
* `FormatFloat` for `'r'`, `'s'`, `'g'`, `'G'`, `'e'`, `'E'`, `'f'`,
  `'F'`, `'%'` codes plus `FloatFormatFlag` (AddDotZero, Alternate,
  AlwaysSign, SpaceSign, NoNegZero). Mirrors `format_float_short`.

### `pymath/`

Thin file mirroring `pymath.c` and `pyfpe.c`:

* `NaN`, `Inf`, `NegInf`, `CopySign`, `IsNaN`, `IsInf`, `IsFinite`,
  `Log1p`, `Hypot` routed through Go's `math`.
* `FPECounter`, `FPEDummy` legacy stable-ABI sentinels.

### `hash/` (full pyhash.c port)

* `Buffer` (SipHash-1-3), `BufferFNV` for the FNV build path.
* `KeyedHash` (`_Py_KeyedHash`), `Pointer` (`Py_HashPointer`),
  `Double` (`_Py_HashDouble`), `GetFuncDef` (`PyHash_GetFuncDef`).
* `HashBits`, `HashModulus`, `HashInf`, `HashImag` numeric constants.
* Reference vectors against CPython under `PYTHONHASHSEED=0` pinned
  in `hash/hash_test.go`.

### `format/`

Port of `formatter_unicode.c`:

* `Spec` plus `ParseSpec` for the
  `[[fill]align][sign][z][#][0][width][,_][.precision][type]`
  mini-language.
* `FormatString`, `FormatInt` (`b`, `o`, `d`, `x`, `X`, `c`, with `,`
  and `_` grouping), `FormatFloat` (delegating digit generation to
  `pystrconv.FormatFloat`).

## Gate

`v04test/gate_test.go` pins the cross-cuts:

* `hash.Buffer([]byte("hello"))` matches CPython's
  `hash(b"hello")` under `PYTHONHASHSEED=0`.
* `pystrconv.ParseFloat` round-trips a panel of inputs to the same
  uint64 bit pattern as CPython.
* `pystrconv.FormatFloat` reproduces CPython's `repr` for the
  thresholds where shortest round-trip switches to exponent form.
* `format.FormatInt(1234567, ',d')` matches CPython's
  `format(1234567, ',d')`.

## Compatibility

* Go: 1.26 or newer.
* CPython behavioural target: 3.14.0+.

## Out of scope

* Full 1:1 port of `dtoa.c`. The wrapper over Go's `strconv` is
  bit-correct (the gate pins it); a faithful source-shape port is
  tracked as a follow-up.
* SipHash-2-4 (CPython's pre-3.13 default). 3.14 ships SipHash-1-3.
* DJBX33A short-string fast path (`Py_HASH_CUTOFF` is 0 in default
  3.14 builds).
* Complex formatter. Lands when the complex type does.
