# v0.8.0 - 2026-05-06

The import drop. After v0.8 the runtime has a working import system:
marshal reads and writes `.pyc` files, the codecs layer handles utf-8,
ascii, and latin-1, and the `imp` package implements the full
sys.modules → frozen → built-in lookup chain. IMPORT_NAME and
IMPORT_FROM bytecodes in the eval loop use the new machinery end-to-end.

## Shipped

### `marshal/`

* `marshal.go` — added `TYPE_LONG` decoder (sign-extended 15-bit
  digits), `FLAG_REF` object back-references, and interned-string
  (`TYPE_INTERNED`) support. Ports `Python/marshal.c` `r_long`,
  `r_ref_reserve`, `r_ref_insert`.
* `marshal.go` — added `TYPE_CODE` round-trip for the 3.11+ code
  object wire format (25-field variant). Ports
  `Python/marshal.c:L1045 r_object TYPE_CODE`.
* `marshal.go` — added `TYPE_SET` / `TYPE_FROZENSET` /
  `TYPE_DICT` / `TYPE_BINARY_COMPLEX` encoding and decoding.
  `fromObject()` helper converts `objects.Object` items back to plain
  Go values for the writer path.
* `pyc.go` — `WritePyc` / `WritePycHash` / `ReadPyc` implement the
  16-byte PEP 552 header: 4-byte magic (`3620 | 0x0D0A<<16`),
  4-byte flags, and an 8-byte payload that is either
  `{mtime, source_size}` (timestamp variant) or `source_hash`
  (hash variant). Ports `Python/import.c` `read_pyc_header`.

### `codecs/`

* `registry.go` — codec registry with `Register` / `Lookup` / `Search`
  and the `CodecInfo` struct. Ports `Modules/_codecsmodule.c` and
  `Lib/codecs.py` `lookup`.
* `builtin.go` — built-in utf-8, ascii, and latin-1 codecs with
  `Encode` / `Decode` entry points and alias normalization
  (`utf_8`, `utf8`, `u8`, `ascii`, `latin_1`, `iso_8859_1`, `l1`,
  `8859`). Ports `Modules/_codecsmodule.c` `_Py_codec_lookup`.

### `imp/`

* `frozen.go` from `Python/import.c`. `FrozenModule` table,
  `RegisterFrozen` / `FindFrozen` / `IsFrozen` / `FrozenList`.
* `frozen_bootstrap.go` — registers the five importlib bootstrap
  names as nil-Code placeholders so `IsFrozen` answers correctly
  before the real code objects are embedded.
* `sysmodules.go` from `Python/import.c` `sys.modules` access layer.
  `GetModule` / `AddModule` / `RemoveModule` / `SysModulesSnapshot`.
* `inittab.go` from `Python/import.c` `PyImport_Inittab`.
  `AppendInittab` / `ExtendInittab` / `FindInitFunc` /
  `InittabSnapshot`.
* `bootstrap.go` from `Python/import.c` `init_importlib` two-phase
  sequence. `Executor` interface for eval-loop injection,
  `InitImportlib` / `InitImportlibExternal` stubs that execute the
  frozen `_frozen_importlib` and `_frozen_importlib_external` code
  objects when they are embedded.
* `exec.go` — `ExecCodeModule` creates a module, registers it in
  sys.modules, executes the code object in its namespace, and removes
  it on failure. Ports `Python/import.c:L632 exec_code_in_module`.
* `loader.go` — `LoadPyc` reads a `.pyc` file and executes it via
  `ExecCodeModule`. `LoadSource` / `LoadSourceFile` compile source
  text through an injected `SourceCompiler` and call `LoadPyc` on
  the result. Ports `Lib/importlib/_bootstrap_external.py`
  `SourceFileLoader` / `SourcelessFileLoader`.
* `import.go` — `ImportModule` / `ImportModuleLevel` implement the
  sys.modules → frozen → inittab lookup chain with relative-import
  resolution via `resolveAbsName`. Ports
  `Python/import.c:L1561 PyImport_ImportModuleLevelObject`.

### `vm/`

* `eval_import.go` — `IMPORT_NAME` and `IMPORT_FROM` bytecode arms
  wired into the eval loop via `vmExecutor` (implements `imp.Executor`
  using `EvalCode`). `tryImport` is consulted by `dispatch` before
  the generated arms. Ports
  `Python/bytecodes.c IMPORT_NAME / IMPORT_FROM`.

### `objects/`

* `module.go` — `Module` type with `__name__` / `__doc__` /
  `__file__` / `__loader__` / `__spec__` dict slots. `ModuleType`
  singleton, `NewModule`, `module_repr`. Ports
  `Objects/moduleobject.c`.
* `set.go` — `Set` and `Frozenset` types backed by
  `map[uint64]objects.Object` with FNV hash keying. `NewSet`,
  `NewFrozenset`, `set.add`, `set.discard`, `frozenset.__hash__`.
  Ports `Objects/setobject.c`.

### `errors/`

* `exc_import.go` — `ImportError` and `ModuleNotFoundError` hierarchy.
  Ports `Objects/exceptions.c`.
