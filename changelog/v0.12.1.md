# v0.12.1 - WIP

The test e2e drop. v0.0 through v0.12 shipped feature work and small
per-package gates (`v04test/`, `v05test/`, `v012test/`), but the
canonical CPython suite at `Lib/test/test_*.py` was never wired up.
v0.12.1 closes that gap version by version: every `ready` test from
the v0.2 through v0.12 panels lands under `test/cpython/` and runs
green through a gopy-driven port of `regrtest`.

The triage table for all 434 CPython 3.14 test entry points lives at
`~/notes/Spec/1700/1700_gopy_test_e2e.md`. The tests that depend on
stdlib modules gopy has not yet shipped (`json`, `pickle`, `re`,
`hashlib`, etc.) are marked `deferred` and stay out-of-tree.

## Shipped

(WIP. Each landed test version drop ticks the triage table from
`ready` to `done`.)

### `test/cpython/`

* Vendored subset of `Lib/test/test_*.py` files for shipped features.
  Files are byte-identical to upstream so future CPython rebases show
  zero noise.

### `test/cpython/support/`

* Vendored `Lib/test/support/` helpers required by the ported tests.

### `test/regrtest/`

* Port of `Lib/test/regrtest.py` driver. Walks `test/cpython/`,
  reads the `MANIFEST.txt` triage state, and drives each test through
  a gopy-driven `unittest` runner.

## Out of scope for this release

- Networking, multiprocessing, asyncio, sqlite3, json, pickle, re,
  hashlib, decimal, ctypes, tk/curses, GUI tests, gdb / dtrace, and
  every CPython-implementation-specific harness. See spec 1700 for
  the full triage.
- Performance benchmarks (`pyperformance`).
