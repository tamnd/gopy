# v0.5.0 - 2026-05-04

The compile pipeline. After v0.5 a Go caller can take a parsed AST
module, run it through symtable resolution, codegen, flowgraph, and
assemble, and get back a Code object plus a dis-style listing.

## Shipped

### `ast/`

* `asdl.go` plus generated `nodes_gen.go` from
  `cpython/Parser/Python.asdl`. Every AST node, every union, every
  field type covered by the source-of-truth grammar.
* `validate.go` from `ast.c`. Field-presence checks, context
  validation, comprehension shape rules.
* `preprocess.go` from `ast_preprocess.c`. Constant folding for
  literals.
* `unparse.go` from `ast_unparse.c`. Round-trips an AST to source.

### `future/`

Port of `future.c`. Detects `from __future__ import` statements and
sets the feature flags (Annotations, BarryAsBdfl, etc.) the rest of
the pipeline reads.

### `symtable/`

Full port of `symtable.c`:

* `Build` walks the AST, opens one Entry per scope, registers every
  binding and reference.
* `analyze.go` runs the post-build resolution pass: free variables
  bubble up, cells get pulled down, comprehensions inline into their
  enclosing function when safe.
* `mangle.go` implements name mangling for class private attributes.
* Errors panel covers every CPython diagnostic the symtable raises
  (assignment to free var, duplicate global, etc.).

### `compile/`

#### `instrseq.go`

Port of `instruction_sequence.c`. Sequence, Instr, JumpTargetLabel,
Addop, Insert, AddNested, ApplyLabelMap.

#### `codegen.go` and the per-statement / per-expression panel

Port of `codegen.c`. Per-scope Compiler driver, Unit handoff. Visitors
shipped:

* Module, Interactive, Expression mods.
* Pass, ExprStmt, Return, Assign, AugAssign, AnnAssign, Delete, Raise,
  Assert, Import, ImportFrom.
* If, While, For, Break, Continue.
* FunctionDef, AsyncFunctionDef, ClassDef, Lambda.
* With, AsyncWith.
* Try, TryStar.
* Match plus the eight pattern kinds (Value, Singleton, As, Sequence,
  Mapping, Class, Or, Star).
* Comprehensions: ListComp, SetComp, DictComp, GeneratorExp.
* Expression panel: BoolOp, BinOp, UnaryOp, Compare, Call, Constant,
  Name, Attribute, Subscript, Tuple, List, Set, Dict, Starred,
  Slice, JoinedStr, FormattedValue, NamedExpr, Yield, YieldFrom,
  Await, IfExp.
* Assignment targets: Name, Attribute, Subscript, Tuple/List unpack,
  Starred (UNPACK_SEQUENCE / UNPACK_EX).

#### `flowgraph.go`

Skeleton port of `flowgraph.c`. Public Optimize entry point,
FromSequence / ToSequence, BasicBlock / Builder model, label
resolution, forward stackdepth analysis with a hand-written effect
table covering every opcode the codegen emits. The full optimisation
panel (jump thread, const fold, swaptimize, super-instructions,
loadfast, cold-block hoist) is on the floor and lands incrementally
per the 1627 spec.

#### `assemble.go`

Port of `assemble.c`. Sequence-to-Code conversion with EXTENDED_ARG
widening, flat 3.11+ co_localsplus layout, varint helpers ready for
the line and exception tables.

#### `compiler.go`

Top-level `Compile(mod, filename, optimize)` driver that walks
symtable to codegen to flowgraph to assemble. Returns a Code object
that the v0.6 interpreter and the marshal package will consume.

#### `dis.go`

Port of `dis.dis`. Renders a Code object as a one-line-per-instruction
listing, recombining EXTENDED_ARG prefixes back into the 32-bit oparg
view. Recurses into nested Code objects attached via co_consts.

### `tokenize/`

Skeleton wrapper around `Python-tokenize.c`. The public Iter / Token /
Type / Pos surface is stable; the underlying lexer state machine lands
with the parser port.

## Gate

`v05test/gate_test.go` pins the end-to-end pipeline:

* An empty module compiles to LOAD_CONST None / RETURN_VALUE.
* `x = 1` round-trips through symtable, codegen, flowgraph, assemble,
  and disassemble, with `co_names == ["x"]` and a single int constant.
* `a = 1 + 2` reaches the BINARY_OP / STORE_NAME path (byte-for-byte
  parity with CPython's constant folder lands once the optimisation
  panel arrives).
* `x = 1; x` round-trips a STORE_NAME / LOAD_NAME pair.

## Compatibility

* Go: 1.26 or newer.
* CPython behavioural target: 3.14.0+.

## Out of scope

* Full optimisation panel from `flowgraph.c`. Jump threading, const
  folding, swaptimize, super-instructions, loadfast ref-stack
  analysis, cold-block hoisting, and pseudo-op lowering remain.
* PEP 626 line table emission and PEP 657 exception table emission.
  The varint helpers ship; the writers land alongside the line-info
  panel from the 1628 spec.
* Per-scope nested Unit recursion in the driver. Nested function
  Codes are emitted at codegen time but not yet recursed through
  flowgraph + assemble; comes with the compile_function port.
* Parser side. `parser.Parse(src) (ast.Mod, err)` is provided by a
  separate spec series. The v0.5 gate exercises the AST-to-Code path
  on hand-built modules.
