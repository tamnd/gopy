# v0.5.0 - 2026-05-05

The compile pipeline. After v0.5 a Go caller can take a parsed AST
module, run it through symtable resolution, codegen, flowgraph, and
assemble, and get back a Code object plus a `dis`-style listing whose
disassembly is pinned by a checked-in golden corpus.

## Shipped

### `ast/`

* `asdl.go` plus generated `nodes_gen.go` from
  `cpython/Parser/Python.asdl`. Every AST node, every union, every
  field type covered by the source-of-truth grammar.
* `validate.go` plus `validate_panel.go` from `ast.c`. Position
  sanity, forbidden-identifier rejection (`None` / `True` / `False`),
  Constant-kind whitelist, comprehension-shape rules, expr_context
  consistency for Name / Attribute / Subscript / Starred / List /
  Tuple, Starred-placement rule, MatchValue / MatchSingleton /
  MatchSequence / MatchMapping / MatchClass / MatchStar / MatchAs /
  MatchOr pattern shapes, PEP 695 type-param constraints.
* `preprocess.go` from `ast_preprocess.c`. PEP 765 finally-block
  control-flow checks, `string % tuple` printf-format fold,
  `Name("__debug__")` substitution, MatchValue / MatchMapping
  numeric folds, `-OO` docstring removal, PEP 563 annotation skip.
* `unparse.go` from `ast_unparse.c`. Round-trips an AST to source
  with operator-precedence parenthesization, infinity rendered as
  `1e309`, and f-string / t-string round-trip.

### `future/`

Port of `future.c`. Detects `from __future__ import` statements and
sets the feature flags (Annotations, BarryAsBdfl, etc.) the rest of
the pipeline reads. SyntaxError strings preserved verbatim.

### `symtable/`

Full port of `symtable.c`:

* `Build` walks the AST, opens one Entry per scope, registers every
  binding and reference.
* `analyze.go` runs the post-build resolution pass: free variables
  bubble up, cells get pulled down, comprehensions inline into their
  enclosing function when safe.
* `mangle.go` implements name mangling for class private attributes.
* Errors panel covers every CPython diagnostic the symtable raises
  (assignment to free var, duplicate global, walrus inside class,
  named-expr inside iterable, async-await placement, etc.).

### `compile/`

#### `instrseq.go`

Port of `instruction_sequence.c`. Sequence, Instr, JumpTargetLabel,
Addop, Insert, AddNested, ApplyLabelMap.

#### `codegen.go` and the per-statement / per-expression panel

Port of `codegen.c`. Per-scope Compiler driver, Unit handoff. Visitors
shipped:

* Module, Interactive, Expression mods.
* Pass, ExprStmt, Return, Assign, AugAssign, AnnAssign, Delete, Raise,
  Assert, Import, ImportFrom.
* If, While, For, AsyncFor, Break, Continue.
* FunctionDef, AsyncFunctionDef, ClassDef, Lambda.
* With, AsyncWith.
* Try, TryStar.
* Match plus the eight pattern kinds (Value, Singleton, As, Sequence,
  Mapping, Class, Or, Star).
* Comprehensions: ListComp, SetComp, DictComp, GeneratorExp.
* TypeAlias via `CALL_INTRINSIC_1 INTRINSIC_TYPEALIAS`.
* Expression panel: BoolOp, BinOp, UnaryOp, Compare, Call, Constant,
  Name, Attribute, Subscript, Tuple, List, Set, Dict, Starred,
  Slice, JoinedStr, FormattedValue, NamedExpr, Yield, YieldFrom,
  Await, IfExp.
* Assignment targets: Name, Attribute, Subscript, Tuple/List unpack,
  Starred (UNPACK_SEQUENCE / UNPACK_EX).

#### `flowgraph.go`

Port of `flowgraph.c`. CFG-driven optimisation driver,
FromSequence / ToSequence, BasicBlock / Builder model, label
resolution, forward stackdepth analysis on a hand-written effect
table. Optimisation passes: int-int BINARY_OP constant folding (run
to a fixed point), jump threading, conditional-jump propagation,
unreachable-block elimination (DFS reachability with handler labels
pinned), dead-code elimination after unconditional terminators,
redundant-NOP compaction. Swaptimize, super-instructions, LOAD_FAST
ref-stack, cold-block hoisting, CFG-based stackdepth, and full
pseudo-op lowering remain for follow-on.

#### `assemble.go`

Port of `assemble.c`. Sequence-to-Code conversion with EXTENDED_ARG
widening, PEP 626 line table (short / one-line / long / no-location /
no-column varint forms), PEP 657 exception table (start, end, target,
depth, lasti as 6-bit varint deltas), type-keyed const dedup with
float bit-pattern keying for NaN-safety, `co_qualname` walk over the
unit stack, full `co_flags` assembly (CoOptimized, CoNewLocals,
CoVarargs, CoVarkeywords, CoNested, CoGenerator, CoNoFree,
CoCoroutine, CoMethod), flat 3.11+ co_localsplus layout.

#### `compiler.go`

Top-level `Compile(mod, filename, optimize)` driver that walks
symtable to codegen to flowgraph to assemble per scope. Returns a
Code object that the v0.6 interpreter and the v0.8 marshal-import
arm will consume.

#### `dis.go`

Port of `dis.dis`. Renders a Code object as a one-line-per-instruction
listing, recombining EXTENDED_ARG prefixes back into the 32-bit oparg
view. Recurses into nested Code objects attached via co_consts.

### `marshal/`

Skeleton port of `marshal.c`: version-5 wire format, encoder/decoder
dispatch, `Dump` / `Load` round-trip on the constant types used by
co_consts. The code-object arm (TYPE_CODE, REF dedup, line/exception
table byte parity) lands in v0.8 alongside the import system.

### `tokenize/`

Skeleton wrapper around `Python-tokenize.c`. Type table generated
from `Grammar/Tokens`, `Include/internal/pycore_token.h`, and
`Lib/token.py` via `tools/tokens_go`. Numeric values pinned to
CPython. The Iter / Token surface and the lexer state machine
arrive in v0.9.

## Gate

`v05test/gate_test.go` pins the end-to-end pipeline structurally:

* Empty module compiles to `LOAD_CONST None` / `RETURN_VALUE`.
* `x = 1` round-trips through symtable, codegen, flowgraph, assemble,
  and disassemble.
* `a = 1 + 2` reaches the BINARY_OP path and the int-int folder
  collapses it to `int(3)` in `co_consts`.
* `x = 1; x` round-trips a STORE_NAME / LOAD_NAME pair.
* `if x: pass` / `while x: pass` exercise POP_JUMP_IF_FALSE.
* `def f(x): return x + 1` produces a nested code object with
  `MAKE_FUNCTION` and `LOAD_FAST`.
* `async def f(): pass` sets `CoCoroutine` on the inner code.

`v05test/golden_test.go` (spec 1629) pins disassembly text against
ten checked-in `.golden` files: `empty_module`, `simple_assign`,
`binary_add`, `load_after_store`, `if_pass`, `while_pass`,
`def_add_one`, `async_def_pass`, `class_pass`, `type_alias`.
Refresh via `go test ./v05test/ -update -run TestGolden`. CI never
passes `-update`.

`TestGateTryExcept` and `TestGateComprehension` are wired but
`t.Skip`'d pending the CFG-based stack-depth analyser (handler entry
seeding / comprehension back-edge).

## Compatibility

* Go: 1.26 or newer.
* CPython behavioural target: 3.14.0+.

## Out of scope (deferred)

* CPython byte-equal marshal parity for code objects. Lands in v0.8
  with the import system; until then disassembly text is the gate.
* CFG-based stack-depth analyser; current pass is a forward linear
  scan. Unblocks `TestGateTryExcept` and `TestGateComprehension`.
* Swaptimize, super-instructions, LOAD_FAST ref-stack, cold-block
  hoisting, full pseudo-op lowering. Tracked in the 1627 spec.
* PEG parser. Separate spec series; v0.5 exercises the AST-to-Code
  path on hand-built modules.
