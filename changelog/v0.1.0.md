# v0.1.0 - 2026-05-04

The first release with executable code. v0.1.0 ports the foundation
that every later subsystem rests on: the compiler-side allocator,
threading shim, synchronization primitives, and the per-process hash
secret. The interpreter still does not run Python code; the next
release (v0.2.0) integrates the object model.

## Added

### `arena/`

Faithful port of `cpython/Python/pyarena.c`. A bump allocator with a
linked list of 8 KiB blocks for the compiler pipeline (parser, AST,
symbol table, codegen). Public API mirrors `_PyArena_*`:

* `arena.New`, `(*Arena).Malloc`, `(*Arena).AddObject`,
  `(*Arena).Free`.

### `pythread/`

Cross-platform half of `cpython/Python/thread.c`, layered over Go
goroutines. The OS-specific `thread_pthread.h` and `thread_nt.h`
files have no Go counterpart and are dropped.

* `pythread.Start`, `(*Handle).Join`, `(*Handle).Ident` for goroutine
  create/join.
* `pythread.Init`, `GetStacksize`, `SetStacksize` stubs.
* `TimeoutMax` constant matching `PY_TIMEOUT_MAX`.

Lock-acquire retry, TSS, and `sys.thread_info` are deferred until
their dependencies (state, pytime, sysmod) land.

### `pysync/`

Port of `cpython/Python/lock.c`, `parking_lot.c`, and
`critical_section.c`. Named `pysync` to make it clear the primitives
are distinct from Go's standard `sync` package.

* `pysync.Park`, `Unpark`, `UnparkAll`, `AfterFork`: 257-bucket
  address-keyed parking lot.
* `pysync.Mutex`: byte-flag mutex with the same locked / has-parked
  bit layout as `PyMutex`, plus 1 ms fair-handoff and the detach hook
  plumbed through.
* `pysync.Event`, `pysync.OnceFlag`, `pysync.RecursiveMutex`,
  `pysync.RWMutex`, `pysync.SeqLock`, `pysync.RawMutex`.
* `pysync.CriticalSection`, `BeginMutex2`, `End`: PEP 703 stack with
  bookkeeping in the GIL build; v0.14 will turn it into real lock
  acquisition under the `pygil_disabled` tag.

The C `_PySemaphore` abstraction is replaced by a buffered
`chan struct{}` inside each waiter.

### `hash/`

Seed-init half of `cpython/Python/bootstrap_hash.c`.

* `hash.Init`, `hash.Reset`, `hash.Secret`, `hash.SecretSize`.
* `PYTHONHASHSEED` parsing matching CPython: `random`, `0`, or a
  positive 32-bit integer.
* The same LCG (constants `214013`, `2531011`, bits 16..23) used by
  `lcg_urandom`. Output is byte-identical to CPython for any seed.
* OS entropy via Go's `crypto/rand`. Drops `_PyOS_URandom*` and the
  `/dev/urandom` fallback as redundant.

The hashing functions themselves (SipHash-1-3, FNV) ship with
`pyhash.c` in v0.4.

## Compatibility

* Go: 1.26 or newer.
* CPython behavioural target: 3.14.0+.
* Build tag `pygil_disabled` is reserved for the future
  free-threaded build (v0.14). v0.1.0 is GIL-build only.

## Known limitations

* No parser, AST, compiler, VM, or standard library yet. The roadmap
  reaches the object model in v0.2.0 and the first executable
  Python in v0.6.0.
* `PyThread_acquire_lock_timed_with_retries`, `PyThread_tss_*`, and
  `PyThread_GetInfo` are not yet ported; they depend on subsystems
  that arrive in later phases.
