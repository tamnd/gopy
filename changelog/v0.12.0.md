# v0.12.0 - 2026-05-08

The Tier-2 drop. v0.12 lays down the full Tier-2 control flow PEP 659
forwards into: a per-install-site executor side table, the
`JUMP_BACKWARD` warmup callback that drives `_PyOptimizer_Optimize`,
projection from quickened bytecode into a uop trace, the analysis
skeleton with the cleanup pass that prunes dead `_SET_IP` /
`_CHECK_VALIDITY` rows, and the uop dispatch loop itself. Trace
install, side-table wiring, the dispatcher, and the deopt arm are
all end-to-end gated. The remaining body-swap work (per-opcode
abstract semantics for `optimize_uops`, the dict / type watcher
folds in `remove_globals`, and the long tail of hand-ported per-uop
bodies behind the dispatch switch) slots in as bodies against the
control flow this release ships.

## Shipped

### `optimizer/`

* `bloom.go`. The 256-bit dependency filter
  (`_Py_BLOOM_FILTER_WORDS = 8`); trace projection adds every
  guarded type / dict / code pointer, the invalidation walk hashes
  a mutated pointer and asks every executor whether it might be
  in scope.
* `types.go`. The shared shapes: `UOPInstruction`, `Executor`,
  `ExitData`, `BackoffCounter`, `JitOptSymbol` lattice (9 tags:
  `Unknown`, `NonNull`, `Null`, `Bottom`, `TypeVersion`,
  `KnownClass`, `KnownValue`, `Tuple`, `Truthiness`), the
  `JitOptContext` arena layout, and the bounds (`UOPMaxTraceLength
  = 800`, `MaxAbstractInterpSize = 4096`, `TyArenaSize`,
  `MaxAbstractFrameDepth`).
* `uop_ids_gen.go`, `uop_meta_gen.go`. Generated tables: every
  `_PyUop_Flags` / `_PyUop_Replication` / per-uop num-popped row,
  with the upstream uop IDs aliased to gopy's `compile.OPCODE`
  constants where the Tier-1 / Tier-2 IDs match (`_LOAD_CONST`,
  `_POP_TOP`, `_NOP`, `_COPY`, `_SWAP`, `_RETURN_VALUE`).
* `executor.go`. Allocate / `ExecutorInit` / link against the
  per-interpreter list / detach from `Code.Executors` /
  `ExecutorClear`. Plus the two-phase free: pending deletions
  queue on `InterpState.ExecutorDeletionListHead` and the sweep
  runs when `RemainingCapacity` underflows so `tp_dealloc` cannot
  race a thread executing the trace.
* `pyobject.go`. The Python-visible executor surface:
  `Executor.GetTrace` returns the uop sequence as a list of
  `(name, oparg, target)` tuples for `dis.dis` to render;
  `is_valid` mirrors the upstream method.
* `side_table.go`. `Code.Executors` packing:
  `hasSpaceForExecutor`, `getIndexForExecutor`,
  `insertExecutor` (sets `VMData.Opcode` / `Oparg` / `Code` /
  `Index`, then patches the bytecode at the install site to
  `ENTER_EXECUTOR`).
* `trace.go`. `TranslateBytecodeToTrace` projection from the
  quickened bytecode to the uop buffer. Walks the instruction
  stream from a warmup site, expands each opcode through the
  `lookupMacro` identity fallback, stamps every guarded
  type / dict pointer into the dependency bloom filter, closes the
  loop with `_JUMP_TO_TOP` when the projector returns to the
  install site, and bails on a return / explicit error before the
  loop edge. Preludes every trace with `_START_EXECUTOR` and
  `_MAKE_WARM`.
* `symbols.go`. The `JitOptContext` lattice helpers
  (`SymNew*`, `SymSet*`, `SymGet*`, `SymIs*`, `SymTruthiness`,
  `SymTupleGetitem`, `AbstractContextInit` / `AbstractContextFini`,
  `FrameNew` / `FramePop`). Per-trace symbol arena, locals + stack
  pool, and the contradiction / out-of-space tripwires from
  `Python/optimizer_symbols.c`.
* `optimize.go`. The `Optimize` warmup-callback entry point,
  `uopOptimize` projection + analysis + fix-up pipeline,
  `prepareForExecution` exit / error stub split, `makeExit`,
  `countExits`, and `makeExecutorFromUops` (wires `_EXIT_TRACE`
  rows to per-exit `ExitData` slots and stamps the executor's own
  pointer into `_START_EXECUTOR.operand0`).
* `analysis.go`. The forward-pass orchestrator. `Analyze` runs
  the three CPython phases unconditionally:
  - `removeGlobals` (stub returning 1; the dict / type watcher
    callbacks land with the watcher infrastructure)
  - `optimizeUops` (init / fini bracket, contradiction and
    out-of-space short-circuits, terminator detection; the
    per-opcode abstract semantics land with the DSL-generated
    case table)
  - `removeUnneededUops` (full port). Walks the trace once,
    NOPs `_SET_IP` and `_CHECK_VALIDITY` where escapes can be
    proved out of reach since `_START_EXECUTOR`, resurrects
    `_SET_IP` ahead of the next escaping uop, and collapses the
    load-then-pop idiom (`_LOAD_FAST` / `_LOAD_FAST_BORROW` /
    `_LOAD_CONST_INLINE` / `_LOAD_CONST_INLINE_BORROW` /
    `_LOAD_SMALL_INT` / `_COPY` paired with `_POP_TOP` /
    `_POP_TOP_LOAD_CONST_INLINE` /
    `_POP_TOP_LOAD_CONST_INLINE_BORROW` /
    `_POP_TWO_LOAD_CONST_INLINE_BORROW`).
* `dis_hook.go`, `uops_print.go`. Format hook for `dis.dis` so the
  `ENTER_EXECUTOR` row prints with the upstream operand layout,
  and the per-uop `_PyUOpPrint` formatter the executor's
  `GetTrace` rides on.
* `uops.go`. The uop dispatcher: `RunExecutor` builds a
  `Tier2State` around the trace, `Run` walks the buffer, and
  per-uop methods on `*Tier2State` return `Tier2Status`
  (`Continue` / `Error` / `Deopt` / `Exit`). `JUMP_TO_TOP` /
  `JUMP_TO_JUMP_TARGET` are encoded as in-method mutations of
  `NextUop` so the switch stays small.
* `uops_impl.go`. Hand-ported per-uop bodies for the trace
  prologue and a starter set of stack / local ops:
  `_NOP`, `_START_EXECUTOR`, `_MAKE_WARM`, `_CHECK_VALIDITY`,
  `_SET_IP`, `_EXIT_TRACE`, `_JUMP_TO_TOP`, `_LOAD_FAST`,
  `_LOAD_FAST_BORROW`, `_STORE_FAST`, `_POP_TOP`, `_PUSH_NULL`,
  `_COPY`, `_SWAP`. The remaining 271 Tier-2-viable uops live as
  `unimplementedUop` stubs in `uops_stubs_gen.go` and bail to
  `StatusDeopt` until their bodies land.
* `uops_dispatch_gen.go`, `uops_stubs_gen.go`. The dispatch switch
  fans every Tier-2-viable uop ID into a method call on
  `*Tier2State`. The generator scans `optimizer/` for hand-ported
  bodies via `go/ast` and writes only stubs for uops that do not
  already have a method, so adding a new port is one file edit
  followed by a regen.

### `vm/`

* `tier2.go`. `tryWarmupTier2` is the per-`JUMP_BACKWARD`
  warmup callback; it bails cheaply when no executor slot is
  available and otherwise calls `optimizer.Optimize`. On success
  the install site flips to `ENTER_EXECUTOR` and subsequent
  passes land in `enterExecutor`. With no uop dispatcher yet,
  every `ENTER_EXECUTOR` deopts: it reads back the Tier-1
  instruction the install path stashed in `Executor.VMData` and
  dispatches it through `trySimple`. `codeExecutorAt`
  encapsulates the `any`-typed `Code.Executors` cast so the vm
  layer stays independent of the optimizer's concrete
  `ExecutorArray`.
* `eval_simple.go`. Wire the warmup site into `JUMP_BACKWARD`
  (computed jump target → `tryWarmupTier2`) and add the
  `ENTER_EXECUTOR` arm that calls `enterExecutor`.

### `objects/code.go`

* Add `Code.Executors` (typed `any` so the vm layer does not
  need to import `optimizer`). Stores
  `*optimizer.ExecutorArray` once the trace optimizer installs
  the first executor for a code object.

### `tools/uops_gen/`

* The DSL generator scaffold. Parses `pycore_uop_ids.h` and
  `pycore_uop_metadata.h` from a CPython checkout and emits
  `optimizer/uop_ids_gen.go` and `optimizer/uop_meta_gen.go`.
  Drift mode hashes the input header and fails CI when the
  recorded hash falls behind upstream, so regeneration is a
  forced step rather than a silent miss. The optimizer-cases
  pass over `Python/optimizer_bytecodes.c` is left for the
  follow-up that lights up the per-opcode abstract semantics.

### `compile/`

* `opcodes.go`. Encode `COMPARE_OP`'s oparg with the comparison
  kind packed in the high bits, matching CPython's pre-
  specializer layout. Unblocks the `comparison_eq` family of
  smoke fixtures deferred from v0.11.

### Gates

* `v012test/optimizer_gate_test.go`. The Tier-2 install gate.
  - `TestOptimizerGateInstall` calls `optimizer.Optimize`
    directly on a tiny `LOAD_CONST` / `POP_TOP` /
    `JUMP_BACKWARD` loop, asserts the install site flips to
    `ENTER_EXECUTOR`, the side table is populated at the right
    slot, the executor stashes the Tier-1 op the install site
    was patched out of, and the trace prelude is
    `_START_EXECUTOR` / `_MAKE_WARM` with `_JUMP_TO_TOP`
    closing the loop.
  - `TestOptimizerGateEnterExecutorDispatch` manually
    constructs an executor whose `VMData.Opcode` is
    `RETURN_VALUE`, runs `LOAD_CONST 0; ENTER_EXECUTOR 0`
    through `EvalCode`, and verifies the deopt path returns
    `None` (proves the arm went through `enterExecutor`, not
    through any other hand-rolled arm or `notImplemented`).
* `v012test/analysis_gate_test.go`. Cleanup-pass gate.
  - `TestAnalysisGateCleanupRunsInOptimize` runs the install
    flow and asserts the post-finalize trace contains no `_NOP`
    rows and no `_SET_IP` rows ahead of the first escaping uop.
  - `TestAnalysisGateBenignBailFromOptimizeUops` blows the
    abstract-interp stack budget through a giant `Stacksize`,
    confirms `Optimize` returns a benign bail (status 0,
    nil executor), and the install site is left untouched.
* `v012test/uops_gate_test.go`. Tier-2 dispatch gate.
  - `TestUopsGateHandPortedHappyPath` drives a hand-built trace
    through every hand-ported uop in turn and asserts the
    dispatch loop terminates with `StatusExit`, the warm bit
    flips, the frame instruction pointer is what `_SET_IP` set
    it to, and the local round-trips through `_LOAD_FAST` /
    `_STORE_FAST`.
  - `TestUopsGateStubReturnsDeopt` hits a stubbed uop
    (`_BINARY_OP`) and asserts the dispatcher cleanly returns
    `StatusDeopt` rather than panicking.
  - `TestUopsGateProjectedTraceTerminates` runs a real
    Optimize-produced trace through `RunExecutor` and asserts
    the loop terminates on either `StatusExit` or `StatusDeopt`,
    so partial-port traces stay runtime-safe.
* `optimizer/uops_test.go`. Direct unit coverage for the
  dispatcher: `_NOP` / `_EXIT_TRACE` round-trip, `_LOAD_FAST` /
  `_STORE_FAST` echo, stub deopt, and the `_CHECK_VALIDITY`
  jump-on-invalid arm.
* `optimizer/analysis_test.go`. Direct unit coverage for
  `removeUnneededUops` (drops redundant `_SET_IP` /
  `_CHECK_VALIDITY`, keeps `_SET_IP` ahead of an escaping op,
  collapses the load-then-pop idiom) and the `Analyze`
  pass-through on an empty trace.

## Pending for v0.13

The v0.12 ship lands trace projection, install, the analysis
skeleton, the dispatch loop, and a starter set of hand-ported uop
bodies. The remaining work is body swaps against the wiring this
release ships:

* The long tail of per-uop bodies. 14 of ~285 Tier-2-viable uops
  are hand-ported; the rest live as `StatusDeopt` stubs. Adding a
  body removes a stub on the next regen, so this is incremental.
* The DSL-generated case table
  (`optimizer/uops_cases_gen.go` from
  `Python/optimizer_bytecodes.c`). Per-opcode abstract semantics
  drive the constant-folding, type-version, and stack-effect
  parts of `optimize_uops`. The orchestrator runs the unwired
  default arm today, so this too is a body swap rather than a
  control-flow change.
* The dict / type watcher infrastructure plus the
  `remove_globals` pass. Folds `_LOAD_GLOBAL_MODULE` /
  `_LOAD_GLOBAL_BUILTINS` / `_LOAD_ATTR_MODULE` rows into
  inline-const loads when the dict version still matches and the
  watcher can prove the dict has not mutated. The
  invalidation walk through `_Py_Executors_InvalidateDependency`
  rides on the watcher fan-out.

The four CPython smoke fixtures left ahead of v0.11
(`comparison_eq` and friends) are unblocked by the COMPARE_OP
oparg fix; full re-enable still waits on a v0.13 specializer
fix-up sweep.

* `_io.File` layered split (`RawIOBase` / `BufferedReader` /
  `TextIOWrapper`) was deferred from v0.10.1 and is still pending.
* The fast (super-instruction) compaction passes in
  `compile/flowgraph` (`swaptimize`, super-instructions,
  LOAD_FAST ref-stack, cold-block hoist) were deferred from v0.5
  and remain open.
