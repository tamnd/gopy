# v0.10.1 - 2026-05-07

The backlog drop. Small isolated ports that piled up across v0.2
through v0.10 finally land here, alongside the language-level
machinery the earlier releases parked: `compile` / `eval` / `exec`,
`__build_class__`, `__slots__`, `super`, `__import__`, `io.open`,
and the `myreadline` dispatch shim that lets a real line editor plug
into the REPL.

## Shipped

### `builtins/`

* `compile.go`. `compile(source, filename, mode, ...)` mirroring
  `Python/bltinmodule.c builtin_compile_impl`. Routes the source
  through the parser at the requested mode (`exec`, `eval`,
  `single`) and returns a `Code` object.
* `eval.go` and `exec.go`. `eval` / `exec` honor the explicit
  `globals=` and `locals=` mappings, fall back to the calling
  frame's namespace when omitted, and accept either a source string
  or a precompiled `Code` object. Ports
  `Python/bltinmodule.c builtin_eval_impl / builtin_exec_impl`.
* `import.go`. `__import__(name, globals, locals, fromlist, level)`
  porting `Python/import.c PyImport_ImportModuleLevelObject`. The
  `from x import y` lowering still routes through this entry.
* `open.go`. `open(file, mode, buffering, encoding, errors,
  newline, closefd, opener)` with full mode-string validation
  (`Lib/_pyio.py:205`); returns the new `objects.File`. `encoding`
  / `errors` / `newline` / `buffering` are parsed and validated but
  not yet honored - the file is utf-8 with universal newlines.
* `iter_map_filter.go`. `map` and `filter` as real iterator types
  (`Objects/bltinmodule.c map_object / filter_object`) rather than
  thin wrappers.
* `aiter_anext.go`, `input.go`, `globals_locals.go`, `round.go`. The
  remaining odds-and-ends from `Python/bltinmodule.c` that v0.7
  parked.

### `objects/`

* `class.go` plus `super.go`. `__build_class__` runs the class body
  in a fresh namespace, populates the `__class__` closure cell so
  `super()` without arguments works, and resolves the metaclass per
  `Objects/typeobject.c type_new`. `super` ports
  `Objects/typeobject.c super_init / super_getattro` end to end.
* `slots.go`. `__slots__` on a user-defined class drops the per-
  instance `__dict__`, allocates a fixed-layout slot array on the
  type, and routes attribute access through `MemberDescr`. Mirrors
  `Objects/typeobject.c type_new_slots / type_new_descriptors`.
* `memoryview.go`. `memoryview(b)` over a 1-D contiguous bytes
  buffer with `__getitem__`, `__len__`, `tobytes`, `tolist`,
  `release`, and the `format` / `itemsize` / `nbytes` / `readonly`
  attributes. Ports `Objects/memoryobject.c PyMemoryView_FromObject`.
* `weakref_collections.go`. `WeakSet`, `WeakValueDictionary`, and
  `WeakKeyDictionary` from `Lib/weakref.py`, plus the `proxy` and
  `CallableProxyType` types (`Objects/weakrefobject.c new_weakref`).
* `traceback.go`. `traceback` is now a real Python type
  (`Python/traceback.c PyTraceBack_Type`) with `tb_frame`,
  `tb_lineno`, `tb_lasti`, `tb_next`. Goes through `tp_getset`
  rather than the v0.7 hand-rolled getattr.
* `frame.go`. Python-level frame wrapper (`Objects/frameobject.c
  PyFrame_Type`) plus the `FastToLocals` snapshot that `locals()`
  inside a function leans on.
* `ellipsis.go`, `capsule.go`, `simplenamespace.go`. The remaining
  small singletons / containers: `Ellipsis`, `PyCapsule`, and
  `types.SimpleNamespace`.
* `slice.go`. `PySlice_Unpack`, `PySlice_AdjustIndices`,
  `PySlice_GetIndicesEx`, plus `slice.indices(length)`. The
  range-iterator split out of `range.go` carries the
  `__length_hint__` big-int math so partly-consumed iterators still
  report the right hint.
* `file.go`. `_io.File` collapses `RawIOBase` / `BufferedReader` /
  `TextIOWrapper` into one object backed by `*os.File` plus a
  `bufio.Reader` / `bufio.Writer`. Methods (`read`, `readline`,
  `write`, `close`, `flush`, `__enter__`, `__exit__`, `readable`,
  `writable`) and attributes (`name`, `mode`, `closed`) match
  CPython 3.14. The split into separate raw / buffered / text
  layers is a 1689 follow-up.

### `myreadline/`

* `myreadline.go`. `Reader` / `SetReader` / `CurrentReader` /
  `Readline` / `StdioReadline` / `ErrInterrupt` ports
  `Parser/myreadline.c PyOS_Readline`. The dispatch hook lets a
  line editor (peterh/liner, a cgo shim to GNU readline, libedit)
  plug in via `SetReader` without the REPL caring; the default is
  the unedited `bufio.Reader` fallback that mirrors
  `PyOS_StdioReadline`.
* `pythonrun/repl.go`. `InteractiveLoop` now calls `myreadline.Readline`
  for every prompt, prints `KeyboardInterrupt` on `ErrInterrupt`
  and continues, and exits cleanly on `io.EOF`. PS2 continuation
  still feeds one logical line at a time; the parser doesn't yet
  surface "input incomplete".

### `vm/`

* `async.go`. `GET_AWAITABLE` and the async-for opcodes
  (`SEND` / `END_ASYNC_FOR` / `CLEANUP_THROW`) from
  `Python/ceval.c` plus the `_PyCoro_GetAwaitableIter` helper.
* `cleanup_throw.go`. `CLEANUP_THROW` now surfaces
  `StopIteration.value` so `yield from` and async-for terminate with
  the expected return value.

### `errors/`

* `exc_warning.go`, `exc_syntax.go`, `exc_os.go`, `exc_unicode.go`,
  `exc_group.go`. Warning + 10 subclasses, `SyntaxError` /
  `IndentationError` / `TabError` / `_IncompleteInputError`,
  `OSError` + 15 subclasses with errno mapping (darwin
  `EAGAIN == EWOULDBLOCK` dedup matches the CPython `ADD_ERRNO`
  order), `UnicodeError` + 3 variants,
  `BaseExceptionGroup` / `ExceptionGroup`, plus
  `FloatingPointError`. Mirrors `Objects/exceptions.c`.

### `compile/`

* `set_function_attribute.go`. `SET_FUNCTION_ATTRIBUTE` for closure
  cells and defaults, replacing the v0.7 hand-rolled `MAKE_FUNCTION`
  trailer. Ports `Python/compile.c compiler_make_closure`.
* `load_global.go`. `LOAD_GLOBAL` with the name index packed into
  bits 1+ and the `PUSH_NULL` flag in bit 0, matching CPython 3.11+.

### `gc/`

* `debug.go`, `stats.go`. `gc.set_debug` / `gc.get_debug` /
  `gc.get_stats` / `gc.is_finalized` plus the callback hooks
  (`gc.callbacks` runs `start` / `stop` events). Ports
  `Modules/gcmodule.c gc_set_debug_impl / gc_get_stats_impl`.
* `garbage.go`. `DEBUG_SAVEALL` populates `gc.garbage` with the
  unreclaimable objects; resurrection detection re-tracks objects
  whose finalizer pulled them back into the live graph.

### `lexer/`

* `cookie.go`. PEP 263 source-encoding cookie. The first two
  physical lines are scanned for `# -*- coding: ... -*-`; the source
  is then transcoded into UTF-8 before tokenization. Ports
  `Parser/tokenizer.c check_coding_spec`.

### `unicode/`

* `format.go`. `PyUnicode_Format` ports the `%`-style formatter
  (`Objects/unicodeobject.c do_string_format`). `%s` / `%r` / `%a`
  / `%d` / `%i` / `%u` / `%o` / `%x` / `%X` / `%e` / `%E` / `%f` /
  `%F` / `%g` / `%G` / `%c` / `%%` plus the flag / width /
  precision parser.

### `imp/`

* `reload.go`. `imp.reload(module)` ports
  `Python/import.c PyImport_ReloadModule` - re-executes the module
  body against the existing module dict so live references stay
  valid.

## Pending for v0.11

* The split of `_io.File` into `RawIOBase` / `BufferedReader` /
  `BufferedWriter` / `TextIOWrapper` with a real codec layer (1689).
  v0.10.1's `File` is utf-8 only and does not honor `encoding=`.
* The GNU readline / libedit cgo bridge that satisfies
  `myreadline.Reader`. The dispatch hook is in place; the
  `Modules/readline.c` extension is the follow-up.
* Multi-line PS2 continuation in the REPL. Needs the parser to
  surface an "input incomplete" signal (bracket counting, triple
  quotes, indented block expected).
* The `_io` module surface (`_io.open`, `_io.FileIO`,
  `_io.BufferedReader`, ...) - v0.10.1 only ships the Python-level
  `open` builtin and a collapsed `File` object.
