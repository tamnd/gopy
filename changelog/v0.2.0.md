# v0.2.0 - 2026-05-04

The object model foundation. Ports the gating subset of `cpython/Objects/`
needed to build a dict, hash a tuple, and iterate a list, all from a
test-only `objtest/` harness. The interpreter still does not run Python
code; v0.6.0 is the first release that does.

## Added

### `objects/`

Core protocol shared by every concrete type:

* `Object` interface, `Header`, `VarHeader`.
* `Incref`, `Decref`. Atomic on the refcount field. Decref invokes
  `tp_dealloc` only if the slot is set.
* `Is`, `Hash`, `Repr`, `Str`.
* `Type` with the v0.2 slot subset: `Repr`, `Str`, `Hash`, `RichCmp`,
  `Iter`, `IterNext`, `Call`, `Dealloc`, plus `NumberMethods`,
  `SequenceMethods`, `MappingMethods`.

Concrete types in v0.2: `int`, `float`, `bool`, `None`, `tuple`, `list`,
`dict`, `slice`, `range`. Bytes, str, set, frozenset are deferred to
v0.4 alongside the real SipHash port. Exceptions land in v0.3.

### `typeobj/`

* C3 linearization (`mro_implementation` from `typeobject.c`).
* `Lookup` walking the MRO.
* Built-in types register their slots through this package.

### `abstract/`

Subset of `abstract.c` needed by the gate:

* `PyObject_Length`, `PyObject_GetItem`, `PyObject_SetItem`.
* `PyNumber_Add`, `PyNumber_Subtract`, `PyNumber_Multiply` with the
  reflected-operand fallback.
* `PyIter_Next`.

### `objtest/`

Smoke tests for the v0.2 gate:

* `TestGateBuildDict`: build, set, get.
* `TestGateHashTuple`: build a tuple, hash it, expect the same bytes
  CPython produces under `PYTHONHASHSEED=0`.
* `TestGateIterList`: build, iterate, sum.

## Compatibility

* Go: 1.26 or newer.
* CPython behavioural target: 3.14.0+.
* Hash for v0.2 uses an all-zero SipHash key. The real key plumbing
  arrives in v0.4 with the `pyhash.c` port.

## Out of scope

* Subtype creation (`type(name, bases, dict)`). v0.7.
* Full descriptor protocol. v0.4.
* Strings and bytes. v0.4.
* Set and frozenset. v0.4.
* Cycle collector. v0.10.
* Free-threading reader paths. v0.14.
